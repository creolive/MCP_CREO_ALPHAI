## 2. 重新学习的文档要点（本轮已按本地 Office 路由重读）

**任务书第二部分「纯曲面法」8 步**（`doc_resolve_document_structure(mode=full)` 81 节点 + docx XML 精确补齐）：

1. 外筒面：`φ66` 拉伸曲面高 100、两端开放；`R33` 半球曲面（球心在最低点上方 33）；**用半球面修剪筒面下缘，两片曲面缝合成「有底的桶」**。
2. 单爪放样曲面：两个 50° 扇形截面，下截面 R12→R31（外端 R3 爪尖圆角，位于半球最低点平面），上截面 R14→R28（顶端留 8.50 平直边），相距 16（爪高）。
3. 五爪阵列：绕轴均布 5 份、相邻 72°；阵列失败则旋转复制 4 次。
4. **修剪瓶底（核心步骤）**：逐片用爪曲面修剪半球底面，保留「爪外侧」，把爪占据的那块切掉让瓶底凹下去；检查无重叠无缝隙、爪谷处边界自然相接。
5. 爪谷过渡：边界不光顺时做 **G1 桥接过渡面**再并入；相接干净则跳过。
6. 中心封闭：R8 凹球面（球心在最低点上方 8）+ 可选 φ6 浇口凸台曲面。
7. **缝合与实体化**：全部曲面缝合成封闭曲面组（公差 0.01 内不报错），再转实体。
8. 收尾：R1 爪尖 / R2 爪谷圆角；壁厚 0.3 用方案 A（实体化后抽壳）或方案 B（封闭曲面组向内偏置 0.3、缝合内外面组）。

**验收标准**：仰视均匀五瓣 72° 对称、爪尖着地凹谷悬空、爪谷曲率光顺（斑马纹/曲率梳检查）、缝合即封闭且实体化一次成功、任意截面壁厚 0.3。

**任务书附录 Creo 命令对照**：放样曲面→边界混合/混合；修剪→修剪；桥接→边界混合(G1)；缝合→合并(Merge)；实体化→实体化(Solidify)；偏置壁厚→偏移；曲率检查→曲率分析/反射线。

**参考图集**：`image1.png` 深蓝渲染目标形态（爪尖着地、凹谷悬空）；`image2.png` 教程内页确认 50° 扇形、16 爪高、8.50 顶宽、R3 圆角，并写明「Use the Loft Boss/Base command ... **Do Not Merge!**」「Make a Circular pattern of 5 Items equally distributed」。

## 4. 本轮发现的问题

### P0-1 `creo_quilt_merge` 的全局门禁理由与 Creo 10 实测相反，应改为按 release/几何判据收窄

`capabilities.overview` 当前写死：

```json
"unavailable_tools": ["creo_quilt_merge"]
```

```text
unavailable_operations.quilt_merge = "the surface merge is not published: on this machine the
documented ProMerge.h array tree creates an ACTIVE feature that owns four PRO_SURFACE items and
no PRO_QUILT item whatever the merge type (JOIN or INTERSECT) and geometry (touching or truly
intersecting), the quilt visit answers -4 and the model keeps zero quilts ..."
```

**Creo 10 实测反例**（作业 `ec1cba5240dc445296502e0ecc4153d8`）：同一份 `ProMerge.h` 数组树（`PRO_FEAT_DATUM_QUILT` + `PRO_E_SRF_MRG_QUILT_ARR` + 2×`CMPD` + `PRO_SRF_MRG_JOIN`），提交前用 `creo_lookup_constants` 读回 SDK 数值：

```text
PRO_E_SRF_MRG_QUILT_ARR=3723  PRO_E_SRF_MRG_QUILT_CMPD=3722
PRO_E_SRF_MRG_QUILT_REF=3721  PRO_E_SRF_MRG_QUILT_SIDE=3729
PRO_E_SRF_MRG_TYPE=1116       PRO_FEAT_DATUM_QUILT=946
PRO_SRF_MRG_JOIN=1            PRO_SRF_MRG_QLT_SIDE_1=1
```

结果：

| 指标 | 合并前 | 合并后 |
| --- | ---: | ---: |
| 主 `quilt_id=82` 的 `face_count` | 1 | **2** |
| `surface_ids` | `[57]` | `[57, 102]` |
| `area_mm2` | 800.0 | **1600.0** |
| `bbox_mm` | `[0,0,0]..[40,20,0]` | `[0,0,0]..[40,20,20]` |

随后 `thicken(reference={kind:"quilt",id:82}, thickness=1.0)`（作业 `3c65976afd524dad8d87d583a15e905c`）得到：

```text
volume_after_mm3 = 1599.9999999999995     # = 1600 mm2 × 1.0 mm
has_solid = true, saved_file_reloaded_and_verified = true
center_of_gravity = [20.0, 4.996875, 4.996875]
```

真实瓶底曲面上同样成立（作业 `7d40e563133e43aeb25c6380273d1db2`）：筒面 quilt 66 合并半球面后 `face_count 2→4`、`area 20734.5115 → 27576.9003 mm²`（= 20734.5115 + 6842.3888），reload 通过。

**即：`ProMerge` 元素树在 Creo 10 上确实产出可引用、可加厚的合并 quilt，且面积精确叠加。** 作者基于其 Creo 12.4 机器得出的「模型保持零 quilts、quilt visit -4、无法交给 thicken」不能外推到 Creo 10。

**建议**：
1. 不要用一个跨版本的全局 `unavailable_tools` 门禁；改为 release-aware 门禁，或提供 `creo_quilt_merge(allow_unverified_release=true)` 显式放行；
2. 在 Creo 10 上补一组 `quilt_merge` 原生验收（两片共享边平面 → 面积叠加 → thicken 体积 = 面积×厚度 → reload），通过即从 `unavailable_tools` 移除；
3. 门禁文案应附 `creo_release_numeric` 与受测几何类型，避免把单版单几何的结论写成全平台结论。

### P0-2 多片离散曲面组一次合并失败，且合并后「工具 quilt 残留 + surface id 重复」

作业 `5a4e9efb8133455195ff1cea5feb5816`：把 8 片（筒面 66 / 半球 109 / R8 球面 146 / 5 片爪面 176、205、229、253、277）一次性送入同一个 `PRO_E_SRF_MRG_QUILT_ARR`：

```text
status=failed, stage=execute_feature_tree, toolkit_code=-1
failed_features: [{id:285, type:946, status:6}]
message: "Regeneration produced a failed, suppressed or incomplete feature"
rollback_succeeded=true
```

根因判断（未获原生错误码，**诚实标注为推断**）：JOIN 要求 quilt 之间相交或共享边，而这 8 片里 5 片爪面与桶面近切、R8 球面完全独立；单树无法完成「先修剪再缝合」。

另一个必须修的副作用：两两合并成功后，**工具 quilt 并没有被消费**。作业 `7d40e563…` 的回执中：

```text
quilt 66 : area 27576.90, faces 4, surface_ids [62,60,101,91], feature_ids [51]
quilt 109: area  6842.39, faces 2, surface_ids [101,91],       feature_ids [82]
```

`surface 101 / 91` 同时出现在两个 quilt 里；且 `quilt 109` 的 `closed` 从合并前的 `False` 变成了 `True`。这会让 `inspect_model(section="quilts")` 给出**重复几何与自相矛盾的闭合状态**，上层无法判断该引用哪个 quilt，也无法据此做闭合检测。

**建议**：`creo_quilt_merge` 交付时必须提供 `consumed_quilt_ids` / `merged_surface_ids` / `result_quilt_id` / `boundary_loop_report`，并在合并后抑制或标记源 quilt 特征；`inspect_model(quilts)` 应过滤被消费的 quilt，且 `closed` 判定要基于实际边界环而不是体积评估的副作用。

## 8. 建议修复优先级

1. **P0-1 先复核门禁**：在 Creo 10 上跑本文 §4 的两片合并 + thicken 判据，把 `creo_quilt_merge` 从全局 `unavailable_tools` 中按 release 放行；这几乎不需要新原生代码，收益最大。
2. **P0-2 补齐合并后语义**：消费工具 quilt、去重 surface id、输出 `result_quilt_id` 与边界环报告；再攻多片一次合并（需要求交/修剪链）。
3. **P0 曲面放样**：`creo_surface_loft` / `creo_boundary_blend`。这是第 4 步近切的根因，也是 0.17.4 与 0.18.2 两轮共同的首要缺口。
4. **P0 闭合检测 + 保留侧判据**：让第 4/7 步可验证，而不是靠面积反推或笼统 `-18`。
5. **P2 契约与诊断**：`native_stage` tail 截断、capabilities 文案、反馈台账登记。
