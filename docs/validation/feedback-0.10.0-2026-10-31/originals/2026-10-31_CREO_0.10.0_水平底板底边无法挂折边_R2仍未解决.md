## 二、R2 复现（本轮用完全正确的配方）

### 操作
1. `creo_new_sheetmetal` → 草图 **YZ 平面 offset=92.5**，单线 `(-116,0.5)→(116,0.5)`；`sheetmetal_wall(depth=185, thickness=1, direction="negative")`
2. 结果：V=**42 920 = 185×232×1**，`center_of_gravity [0,0,0.5]` → X±92.5 / Y±116 / Z0~1，**与 TXT §4.1 完全一致** ✅
3. `inspect_model(edges)` 核对：边 **104/105/106/107** 起终点均为 **Z=0.0**（底板四条下边，与 0.3.x 时代完全一致）
4. 挂四道 `sheetmetal_flange`（h=80, R2.54, Y=0.5）

### 结果
- `f_px`(104)、`f_nx`(105) **成功**
- **`f_ny`(106) 失败**：
  ```
  sheetmetal_flange cannot attach to edge 106: ProSmtedgeContourGet returned
  PRO_TK_BAD_CONTEXT (-8), so this edge is not on a sheetmetal wall face
  (green/white contour).
  ```
- `f_py` = not_executed，整批回滚到只剩底板。

### 判读
- 这次**排除了上一轮所有"用法错误"的可能**：正确平面、正确参数、正确边 ID（与 0.3.x 完全相同的配方）。
- 报错文案仍在引导使用者"用 `depth=plate size, thickness=sheet thickness` 重建底板"——但**这正是当前用的写法**。说明该提示**对本场景无效**，反而会误导。
- **根因指向**：`sheetmetal_wall` 在"depth 沿全局 −X、thickness 沿全局 Z"这种构造下，生成的钣金转换体中，**Z=0 的两条长边（106/107）没有被登记为 wall-face（green/white）轮廓边界**，而 X=±92.5 的两条短边（104/105）被登记了。这与 Creo 里"第一壁的折弯侧"判定有关。
- **本质**：这与 S3（四壁折边第 3 道失败）**很可能是同一个根源**——0.3.x 时第 3 道（±Y 方向）失败、本轮第 3 道（−Y 方向）失败，方向一致；只是 0.9.0 起失败点从"创建折边时再生失败"提前到了"挂接边被钣金上下文拒绝"。

### 建议（给作者）
1. **请先在 Creo UI 里人工复现**：YZ 平面画 232 的线 → 轮廓弯边/拉伸壁 depth=185, t=1, 方向 −X → 对 Z=0 的 −Y 边做"平整壁 80mm"。若 UI 里同样失败，说明这是 Creo 对该构造的原生限制，MCP 应在**文档**写明"水平底板请用 X‑normal 平面 + depth 沿 X"或直接拒绝该构造；若 UI 能成功而 MCP 不能，则是 Toolkit 元素树（折弯侧/固定侧属性）的差异，请重点核对 `SMT_*` 属性的设置。
2. **修报错文案**：`Build the base with sheetmetal_wall(depth=plate size, thickness=sheet thickness)` 这句话在本场景下会把使用者引向错误方向（他们已经在用这个写法）。建议改为提示具体方向问题："若底板法线为 +Z 且 depth 沿 −X，请改挂 X=±92.5 的边，或改用 XY 平面构造并交换 depth/thickness"。
3. **在 `edges` 里给出 `flange_available` 标记**（连续第三轮建议）：`ProSmtedgeContourGet` 的结果可以在 inspect 时顺带算好，使用者就不用逐边试错。
4. 提供折弯释放参数或自动角部处理（S3 的第 3/4 道在 UI 里通常也需要释放/斜接）。
