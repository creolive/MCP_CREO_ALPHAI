## 0. 结论先行

**本轮把「全程曲面法」从头到尾实跑了一遍，结论是：0.17.4 造曲面片的能力比发布说明写得更强，但完整链路仍断点在中间，做不出任务书要求的封闭缝合实体化五爪瓶底。**

三个必须说清的事实：

1. **新增正证据（作者发布说明未覆盖）**：`extrude(mode="surface")`、`revolve(mode="surface")`、`revolve(mode="surface", angle=50)`、`axis_pattern` **作用在曲面特征上**、`surface_trim`（基准面工具）、`thicken`（单片 0.3）、闭合 quilt 的 `solidify` 在 Creo 10 上全部实跑成功，且面积/体积与解析值逐项吻合。`capabilities.families.surface_solid.scope` 目前只写 "planar fill, thicken and solidify"，**漏报了曲面拉伸/旋转/扫掠与曲面阵列**，建议补进契约。
2. **第一条断点（几何层）**：任务书第 2 步「两个 50° 扇形截面做**放样曲面**」没有工具 —— `loft(mode="surface")` 提交前拒绝，无 `creo_surface_loft` / `creo_boundary_blend`。用几何等价的 50° 曲面旋转替代后，锥面爪与 R33 半球**近切**，`surface_trim` 报 `feature_status=6`；同一模型换横切基准面修剪立刻成功，证明是**缺多截面放样曲面**导致切不出五瓣，而不是修剪工具坏了。
3. **第二条断点（拓扑层）**：`quilt_merge` 仍门禁，7 片开放 quilt 无法缝成封闭曲面组；`solidify` 因此拒绝（`ProQuiltVolumeEval=-18`）。正对照：单个闭合 R8 球面 quilt 的 `solidify` 一次成功（2144.66 mm³ = 4/3π·8³），**说明整条「曲面→实体化」链路只差合并这一步**。

此外本轮发现两个新的可操作问题：**修剪保留侧缺少几何判据**（任务书自评的「胜负手」）、**曲面偏置距离在弯曲 quilt 上不可测量**，以及三维契约文案漏报。详见 §5。

## 4. 为什么做不到：两条断点

### 4.1 断点一：缺多截面放样曲面 → 爪曲面与半球近切，第 4 步修剪失败

任务书第 2 步要求两个 50° 扇形截面放样成曲面。0.17.4 没有 `creo_surface_loft` / `creo_boundary_blend`，`loft(mode="surface")` 被 `capabilities.require_available` 在创建 job 前拒绝。`docs/development/G5-NATIVE-CONTRACT.md` §2.8 已把 `SurfaceLoftOp`（`sections` 长度 2）写进契约，但结论是「`surface_loft` 保持未开工」，原因是本机 SDK 无 `ProBlend.h`、四类候选元素树全被内核拒绝（−18 / −2），需要一份手工 Boundary Blend 的 `dump_tree` 参照树。

本轮用「同轴同角度两截面直纹放样 ≡ 锥面」的几何等价路线，以 `revolve(mode="surface", angle=50)` 造出爪曲面。但按任务书尺寸（R33 半球、爪 R31→R28 @ z −33→−17），锥面与球面只在 **r≈28.05、z≈−17.3** 附近一条极窄带相交，属近切：

```
hemisphere: z_s(r) = -sqrt(1089 - r²)
petal cone: z_p(r) = (31-r)/0.1875 - 33
r=28.0 → z_p=-17.00, z_s=-17.46  (cone 在球内)
r=29.0 → z_p=-22.33, z_s=-15.75  (cone 在球外)
```

`surface_trim` 因此报 `feature_status=6`、`check that the tool actually intersects the target quilt`。同一模型上把工具换成 z=−16 横切基准面即成功（面积减半），**排除了工具本身失效**。结论：任务书第 4 步「逐片修剪出五瓣」在 0.17.4 上不可执行，根因就是缺能真正切进球面的多截面/边界混合曲面。

### 4.2 断点二：缺 quilt 合并 → 无法封闭 → `solidify` 拒绝

7 片曲面全部 `closed=false`（`ProQuiltVolumeEval` 一律 `−18 / quilt_is_open`）。`creo_quilt_merge` 虽在 `server.py:2711` 有函数签名（docstring 甚至写了 `result_quilt_id`、merged area、closure status），但被列入 `unavailable_tools` 且提交前门禁：

> `quilt_merge: the surface merge is not published: on this machine the documented ProMerge.h array tree creates an ACTIVE feature that owns four PRO_SURFACE items and no PRO_QUILT item whatever the merge type (JOIN or INTERSECT) and geometry (touching or truly intersecting), the quilt visit answers -4 …`

于是第 7 步「缝合公差 0.01 内不报错」无从执行，`solidify` 明确拒绝开放 quilt。**正对照**：单个 R8 球面 quilt `closed=true`，`solidify` 立刻产出 2144.6606 mm³ 实体并保存重载通过 —— 证明实体化实现没问题，缺的只有合并。

### 4.3 方案 B（偏置 0.3）同样不可行

`surface_offset` 在弯曲 quilt 上的实测：`quilts` 计数不变（7→7，没有新偏置曲面），却把模型从 `has_solid=false` / 0 mm³ 变成 `has_solid=true` / **986.2362 mm³**；`measured_offset_distance_mm=null`、`offset_distance_status.reason="source_quilt_not_a_single_plane"`。也就是说它造的是「可产生实体体积的偏置壁」，既不是独立偏置 quilt，也**无法验证 0.3 这个壁厚**。任务书方案 B「向内偏置 0.3 后缝合内外面组」两步都做不到。相对地，`thicken` 在单片上的 0.3 是精确的（ΔV=面积×0.3），但只能得到孤立的一片壳，不是整体瓶底。

## 6. 本轮新发现的问题（非已知门禁）

### 6.1 【P1 · 新】`surface_trim` 成功后仍无法引用修剪结果 quilt，且保留侧无几何判据

成功作业 `9cef63f5…` 回执：

```json
"kept_quilt_id": 105,
"kept_quilt_source": "retrimmed_target_quilt_visit_failed",
"kept_quilt_visit_code": -4,
"kept_side_basis": {
  "centroid_status": {"available": false, "reason": "quilt_centroid_not_measured"},
  "tool_kind": "datum_plane", "tool_normal": [0,0,1],
  "side_reference": "tool_plane_normal"
}
```

而失败作业 `2e91f248…` 中 `regeneration.owned_quilt_ids=[]`、`owned_quilt_visit_code=-4`。这与 0.11.5 反馈的 `ProFeatureGeomitemVisit(PRO_QUILT) -4` 同源，说明 **trim 结果特征至今不能作为 `quilt_feature` 被下游按标签引用**，黑盒只能靠 `inspect_model(section="quilts")` 读回显式 id。更关键的是任务书第 4 步要求「保留爪外侧」，而 quilt 工具时 `tool_normal=null`、无质心、无保留区域 bbox，只有 `keep_side: one|two` 两个抽象值 —— 判分要点里的「修剪方向」在 0.17.4 上**没有任何几何判据可依据**。建议见 §5 #4。

### 6.2 【P1 · 新】弯曲 quilt 的偏置距离不可测量，0.3 壁厚无法验收
