# MCP_CREO_MechDog 配电箱重建总结（v0.17.1）——钣金箱体可建，但增料封堵致百叶/凸台/铰链无法一体成形

- **日期**：2026-11-07
- **被测版本**：**v0.17.1**（`current = latest = 0.17.1`）
- **任务**：依据 `配电箱_跨软件自然语言建模说明.txt`，**仅用 MCP_CREO_MechDog** 重建配电箱，几何 100% 取自该 TXT，不导入任何外部实体；成果保存到 `out4/`
- **一句话结论**：钣金链路这次基本够用——中心底板、四壁、第二段框边、第三段止口、门板四边折边、门板窗口/槽/孔、两件打开姿态装配全部按 TXT 建成，箱体最高 **Z=87.0**、门板 **Z=-1..9** 精确命中。**但仍有两处硬边界**：① 钣金体不能增料（`SHEETMETAL_SOLID_ADD_UNSUPPORTED`），导致 12 个百叶罩壳、4 个冲压凸台、2 个铰链座+销、门板 2 个铰链耳**无法与本零件一体成形**；② 同一段的多条折边无法四边闭合，第二/三段只做成 2/4 边。

## 三、发现的 MCP 能力不足（核心问题）

### 3.1 🔴 钣金体不能增料，TXT 里所有"与壁一体"的凸起特征都无法建

实测（`out4_box`，rev6 提交铰链座 6×10×8 拉伸）：

```
SHEETMETAL_SOLID_ADD_UNSUPPORTED: Creo rejects an extrude add that merges solid material
into a sheetmetal body (ProFeatureWithoptionsCreate returns -1, measured on Creo 12.4.0.0
with and without overlap). Add material with sheetmetal_wall or sheetmetal_flange, or
request new_body=true to create a separate solid body; cut, surface and thin extrudes are
unaffected.
```

这条错误**测得很准，错误码也清楚**，但它直接否掉了 TXT 的四类特征：

| TXT 特征 | 需要的操作 | 现状 |
|---|---|---|
| 百叶罩壳（12 个，§5） | 薄壳增料并与侧壁合并 | ❌ 无法一体 |
| 底板冲压凸台（4 个，§7） | 旋转薄壳增料并与底板合并 | ❌ 无法一体 |
| 铰链座（2 个，§8） | 6×10×8 拉伸增料 | ❌ 无法一体 |
| 销（2 个，Ø3×2） | 圆柱增料 | ❌ 无法一体 |
| 门板铰链耳（2 个，§11） | 8 mm 拉伸增料 | ❌ 无法一体 |

`new_body=true` 虽然能建独立实体，但 TXT 明确要求"与底板是一体成形结构，不是四个单独螺母或圆柱垫块"（§7.1）、"壁与框边应布尔合并成为一个箱体零件"（§4.6）。**请作者补一条"钣金件上的附着增料"通路**：例如允许 `add` 在钣金体上以 `new_body=true` 建 body 后再 `boolean_bodies(union)` 合并（当前钣金体是否支持 boolean 未知），或提供 `sheetmetal_boss`/`sheetmetal_louver` 这类成形工具。这是本轮最大的能力缺口——**它让"薄壁钣金箱"只能停留在光板 + 折边 + 切除**。

### 3.2 🔴 同一段的多条折边无法四边闭合

按 §4.3 建第二段框边时：先做 Y=±116 两条（各 177.9 长，成功），再做 X=±92.5 两条时发现——**X 侧壁顶部只剩中间 70.6 mm 可挂**：

```
id=776  L=70.6  [92.5,35.29,80] -> [92.5,-35.29,80]   contour=0
id=777  L=70.6  [91.5,35.29,80] -> [91.5,-35.29,80]   contour=0
```

原因是先做的 Y 侧框边在角部占位（其 span 到 X=±88.96），把 X 侧壁顶边的两端吃掉了。`miter_cuts` 只解决"**单条**折边的端部让位"，不解决"**同段相邻折边共享角部**"。同理第三段止口也只能做 2/4 边。

TXT §4.5 允许"四角可做斜接缝或小开口"，但当前实现连"斜接"都做不出来——它是让位，不是对接。**建议**：支持同段多边连续框边（内建 corner relief / 共享角部 / 按"矩形环"一次成形的能力），或提供 `sheetmetal_frame(rect, width, height)` 这类把四条边当一个特征处理的算子。

### 3.3 🟠 `edge_geometry` 的 1e-6 容差对多道折弯后的坐标过严

建第三段止口时传 `tolerance_mm=1e-6`，报：

```
edge_geometry endpoints [-71.790000,-96.000000,80.000000] and [71.790000,-96.000000,80.000000]
matched none of the 248 straight model edges (tolerance_mm=0.000001)
```

而同一条边（inspection 里 ±71.79）把容差放宽到 **0.01** 后立刻成功。也就是说：多道折弯累积后的坐标是"看起来对、实际差几个 1e-4"的值，1e-6 反而更难用。**建议**：默认容差放宽到 1e-3 量级，或在 `matched none` 时回显"最近的 N 条候选边及其端点偏差"，让使用者知道差多少。

### 3.4 🟠 空装配的 `preview` 语义与空零件不一致

`creo_new_assembly` 建出的空装配返回 `preview_status="failed"`（`preview_code=0`），而空零件返回 `skipped_no_geometry`。空装配没有几何是正常状态，不应报 failed，容易让人以为装配建坏了（本轮实际是正常的，后续加组件即 `written`）。

### 3.5 🟠 缺少参数化阵列/成形算子，64 孔格栅只能手工堆草图

TXT §6 要求每侧 32 个环扇孔（三圈环筋 + 八根辐条），即单侧 4 组 × 8 个、两侧共 64 个闭合轮廓，每个轮廓 2 直线 + 2 圆弧。当前只能：
- 在一个 `sketch` 里逐个实体写死（单侧 32 孔 ≈ 128 个实体，两侧 256 个，plan JSON 体积与建模时间都很大），或
- 切 1 个孔再用 `axis_pattern` 阵列 8 次（但需要先有 `datum_axis` 作为轴，且 4 组孔的 r1/r2 不同，要 4 轮"切+阵列"）。

**建议**：提供 `grille`/`louver` 参数化算子（输入中心、外径、环筋半径表、辐条角度表、板厚），或至少让 `sketch` 支持"环形阵列实体"这一层语法，把 64 孔的输入压到几十行。这也是 `out3/out4` 一直没能把格栅做完的直接原因。

## 六、建议（按对"能否完整重建"的影响排序）

1. 🔴 **钣金体附着增料**（§3.1）：给出原生可行路径，或明确 `new_body=true` + `boolean_bodies` 是否支持钣金体合并。这一条不通，TXT 的百叶/凸台/铰链/耳永远是缺口。
2. 🔴 **同段多边连续折边**（§3.2）：corner relief / 共享角部 / 矩形环一次成形。
3. 🟠 **参数化格栅与百叶算子**（§3.5），或 `sketch` 支持环形阵列实体。
4. 🟠 `edge_geometry` 容差默认值与"最近候选边"诊断（§3.3）。
5. 🟠 空装配 `preview` 归为 `skipped_no_geometry`（§3.4）。
6. 🟡 `extrude` 报"removes no material"时回显 sketch 法向与建议方向。
