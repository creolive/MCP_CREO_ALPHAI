# BUG-077 图纸引用消费点实机验收与拆分遗漏修复（第 3 组）

日期：2026-10-22。开发者侧实机。环境同[恢复链路记录](BUG077-RECOVERY-2026-10-22.md)（会话指纹 `6265530161255170365`）。

## 发现的缺陷与修复（随版交付）

第 3 组验收首轮即暴露两处 BUG-077 拆分改动的遗漏（此前无实机图纸用例，0.4.6 及之前未触发）：

1. **`run_drawing` 未做引用内联化**（native/drawing.cpp）：worker 入口按 `model_type=="drawing"` 分流到独立的 `run_drawing`，它没有 `run_generic` 中 BUG-077 新增的"组件源/模型详情 `*_ref` 解析回内联"处理——对拆分形态（0.4.7 起所有新登记）模型创建图纸时 `source["inspection"]` 落空为 null，native 抛 `[json.exception.type_error.305]`（失败作业 `b5c8d6a6…`）。修复覆盖四条路径：请求读取（aliases_ref/组件内联）、编辑已有图纸的 `verify_drawing` 前置校验、失败回滚路径（aliases/inspection 引用优先）。
2. **`owned_file` 扩展名不含图纸**（src/creo_mechdog/reconciliation.py）：图纸专用工具（`creo_drawing_view` 等）的源文件校验把 `.drw` 按 `prt` 匹配必然拒绝。修复：`{"assembly": "asm", "drawing": "drw"}` 映射。

修复后 `bridge.py build` 重编译，全量单测 530 项、`tools/dev_check.py` 与 `tools/test_general.py`（7/7）通过。
