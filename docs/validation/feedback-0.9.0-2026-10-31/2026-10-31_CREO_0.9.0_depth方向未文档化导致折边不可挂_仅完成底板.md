## 二、核心问题 R2：`depth` / `thickness` 的"几何方向"仍未被文档说清，且报错给的修法会把人带偏

### 2.1 事实
| 写法 | 结果 | 判定 |
|---|---|---|
| 草图 XY、线沿 X 于 v=0.5；`depth=1, thickness=232` | 185×232×1，`cog=[0,0,0.5]`（**水平板** ✓） | 体积/朝向都对 |
| 草图 XY、线沿 X 于 v=0.5；`depth=232, thickness=1, direction=negative` | 体积同为 42 920，但 `cog=[0,0.5,-116]` → 实际是 **185(X)×1(Y)×232(Z) 的竖直板** | ❌ 方向错 |

即：**`depth` 仍然是"垂直草图平面"的方向，`thickness` 仍然是"面内垂直于草图线且以草图线为中心"的方向** —— 与 0.3.x 时代完全一致，**并没有因为 S5 的修复而改变**。

### 2.2 由此产生的最坑问题
- 用 `depth=1, thickness=232` 建出的是**几何完全正确的水平底板**（体积、质心全对）。
- 但随后 `sheetmetal_flange` 挂 Z=0 底边时报：
  ```
  sheetmetal_flange cannot attach to edge 121: ProSmtedgeContourGet returned
  PRO_TK_BAD_CONTEXT (-8), so this edge is not on a sheetmetal wall face (green/white contour).
  ... Build the base with sheetmetal_wall(depth=plate size, thickness=sheet thickness) ...
  ```
- **而这条建议（`depth=plate size, thickness=sheet thickness` = `depth=232, thickness=1`）在 XY 平面上会得到竖直板**（见 2.1 第二行）—— 也就是：**照报错提示改，朝向就错了；照朝向改，折边就挂不上。** 使用者会被卡死。

### 2.3 建议（作者侧，优先级最高）
1. **错误提示不要只给"参数该写什么"，还要给"在哪个草图上写"**。本例正解是"换到 YZ 平面 + offset"，而不是在原地改 depth/thickness。建议把提示改成：
   > 若目标是 Z 向法线的水平板，请在 **YZ 平面（或 YZ 平移面）** 上画沿 Y 的线，再 `depth=面内长度, thickness=板厚`。
2. **返回里回显几何解释**：`{"extrude_dir":"-X","sheet_normal":"+Z","plate_size":[185,232],"sheet_thickness":1,"wall_face_id":…}`，让使用者一眼确认"板法线是不是我想要的 Z"。
3. **不要让"体积正确"掩盖方向错误**：体积/质心对但拓扑不可用，是最难自查的一类错误。建议 `sheetmetal_wall` 结束时顺带做一次"wall face 是否可被 flange 使用"的自检，并对不可用的情况**警告**。

## 三、次要问题

### 3.1 `sheetmetal_flange` 的可用边范围仍不透明
`PRO_TK_BAD_CONTEXT (-8)` 说明"这条边不在钣金壁面上"，但使用者从 `inspect_model(section=edges)` 里**看不出来哪条边可挂**——边记录只有 `adjacent_surfaces` 与端点坐标，没有"是否 wall-face 边界"的标记。
**建议**：在 `edges` 里加 `flange_available: true/false`（或 `sheetmetal_edge_kind`），或在 `curves`/`surfaces` 里给 `sheetmetal_type`（0.9.0 的 surfaces 已有 `sheetmetal_type`，edges 可以对齐）。

### 3.2 `creo_execute_plan` 不能自动建钣金件（行为变更，建议写入文档）
不带 `model_id` 提交 `sheetmetal_wall` 会报 `Sheetmetal operations require an MCP sheetmetal model`。0.7.x 可直接提交。建议在工具描述里写明"钣金计划必须先 `creo_new_sheetmetal`"。

### 3.3 新模型 `revision` 起点
`creo_new_sheetmetal` 返回 `revision: 0`，但立即用 `expected_revision: 0` 提交会报 `Stale revision: current model revision is 1`。建议返回实际可用值。
