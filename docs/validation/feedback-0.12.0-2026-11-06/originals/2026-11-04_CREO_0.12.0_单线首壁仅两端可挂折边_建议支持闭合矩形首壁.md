## 二、R2/S3 复现与根因（本轮最大收获）

### 复现（与 0.10.0 完全相同的正确配方）
1. YZ 平面 offset=92.5，单线 `(-116,0.5)→(116,0.5)`，`sheetmetal_wall(depth=185, thickness=1, direction="negative")` → V=42 920，cog `[0,0,0.5]` ✅
2. 四道折边 h=80 / R2.54 / Y=0.5 → `f_px`(104) ✅、`f_nx`(105) ✅、**`f_ny`(106) ❌**、`f_py` not_executed

### 根因（由 0.12.0 的 `wall_contract` 揭示）
`aliases` 里 `w_wall` 现在返回：
```json
"wall_contract": {
  "driving_axis": 2, "driving_face_id": 62,
  "frame": { "depth_direction": [-1,0,0], "thickness_direction": [0,0,-1], "sketch_normal": [1,0,0] },
  "line_length_mm": 232.0,
  "wall_face_ids": [103, 113],
  "wall_face_ids_complete": true,
  "part_thickness_mm": 1.0, "measured_volume_mm3": 42920.0
}
```
对照边的邻接面：
- **edge 104**（+X，Z=0）：邻接面 `[124, 103]` → **包含 wall face 103** → 可挂 ✅
- **edge 105**（−X，Z=0）：邻接面 `[128, 103]` → **包含 wall face 103** → 可挂 ✅
- **edge 106**（−Y，Z=0）：邻接面 `[103, 129]` → 也包含 103，但 `ProSmtedgeContourGet` 报 `-8` ❌

再看几何关系就清楚了：
- **edge 104 / 105：与草图线垂直**（是"线段两端"产生的边）
- **edge 106 / 107：与草图线平行（共线）**（是"线拉伸出的两条长边"）

**结论：单线首壁只有"线两端"的两条边被 Creo 认作可挂折边的壁面边界；与草图线平行的两条长边不行。** 这与 0.3.x → 0.12.0 的全部失败现象一致（历轮失败的都是与原草图线平行的 ±Y 边）。

另外 `native_log` 新增的 `WALL_CONTOUR_QUERY checked=12 bounded=0` 说明在该状态下 Creo 认为整块板**没有任何边**处于 wall-face 轮廓上（与 `wall_face_ids` 的自有记录不一致），这本身就说明"thin extrude → native conversion"没有把长边登记进钣金轮廓体系。

### 这正是 TXT §4.1 的原始描述
> 4.1 底板：**在XY平面绘制中心矩形**，宽185毫米、长232毫米…板厚1毫米，实体占Z=0～1。

即原始设计意图就是**闭合矩形首壁**，而不是单线。单线首壁只是当前 MCP 的实现方式。**建议支持闭合矩形（或多段闭合线）作为 `sheetmetal_wall` 的第一壁** —— 这样四条边都是壁面边界，四壁折边即可一次挂成，S3 自然解决。

### 报错文案（本轮已大幅改善，值得肯定）
现在的报错会把 frame contract、`wall_contract.wall_face_ids`、以及 `examples/sheetmetal_base_yz.json` 冻结配方一起给出：
> Frame contract: depth grows one-sided along the signed sketch normal and thickness is the sheet gauge spread centered on the sketch line, so the green/white wall faces are the gauge faces (see wall_contract.wall_face_ids). … the frozen recipe with coordinates is examples/sheetmetal_base_yz.json.

这正是我前几轮要的"回显语义 + 指向示例"。**建议再补一句：单线首壁仅线两端可挂折边；需要四边可挂请用闭合轮廓首壁。**

## 三、0.12.0 诊断增强（值得肯定，逐项列出）

1. **`wall_contract`**（钣金）：`driving_axis/driving_face_id/frame(depth/ thickness/sketch_normal)/line_length/wall_face_ids/expected_volume/measured_volume/part_thickness_synced` —— 本轮定位根因全靠它。
2. **`weldability`**（草图）：`weldable / max_endpoint_gap_mm / weld_tolerance_mm / exceeding_pairs`，并附 note 说明"开口轮廓无法用焊接补边"。
3. **`geometry_deviation`**（草图）：分 `section_regenerate` 与 `complete_feature` 两个阶段给出最大偏差、平移量、逐实体 sample —— 能直接发现"截面被求解器挪走"这类问题。
4. **`verify_stages`**：把 verify→save→erase→reload→compare 全流程的耗时逐阶段列出（本轮 13 个阶段，总计约 8 s）。
5. **`datum_display`**：预览时的基准面显示/恢复状态与 config 是否写入。
6. **`native_progress`**：原生日志的字节数、阶段、是否截断。

## 四、建议（按收益排序）

1. 🔴 **支持闭合矩形（多段闭合线）作为 `sheetmetal_wall` 首壁** —— 这是解决 S3 的正解，也正是 TXT §4.1 的原意；顺带可支持"非矩形板"（带缺口/异形底板）。
2. 若暂不做闭合轮廓，请在**文档与报错**中明确："单线首壁仅线两端两条边可挂折边；与线平行的长边不可挂"，并在 `edges` 里给出 `flange_available` 标记（连续第五轮建议，现在 `wall_contract` 已有数据，实现成本低）。
3. 提供折弯释放（bend relief）参数；四壁成型后第 3/4 道折边在 UI 中通常也需要释放/斜接。
4. 历史项仍未修：S2（`flip` 无效/折边方向不可控）、S6（`unbend` 的 `fixed_surface` 不接受 datum_plane）、P3（dict plane `offset≠0` 被拒）、P5（装配旋转欧拉角反手）、P11（无 `native_bundle` 打包导出）。建议一并排期。
5. `wall_contract` 里 `part_thickness_synced: false` 的含义建议在文档中说明（何时为 true）。
