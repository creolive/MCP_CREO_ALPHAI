转换 route 冻结为 `strip_prism`：每组 3 个独立 datum point → 三点 datum plane → 坐标草图三角形 → 对称厚度拉伸。它是分站三角棱柱近似，不等于连续扭转曲面。草图二维坐标按 A→B 为 u 轴，C 在该方向的投影及垂距计算；点标签按 `(源特征 label, 点名)` 生成。96 组中的 p_a/p_b/p_c 每组重新绑定，不能全局按点名替换。正交方向与法向的实机有效性仍待验证，依赖 Q05 三点平面及 Q06 斜面草图。
