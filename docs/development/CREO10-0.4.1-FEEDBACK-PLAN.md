## 2. 磁盘打开接口：FEAT-044

新增 `creo_open_file(file_path, idempotency_key)`，提交后返回 `job_id`，通过 `creo_get_job` 查询终态。

- 接受 Windows 本机绝对路径，支持 `.prt`、`.prt.N`、`.asm`、`.asm.N`。显式版本只打开指定文件；省略版本时选择同目录最高数字版本，无数字版本才使用无后缀文件。数字版本存在歧义时拒绝。
- 返回请求路径、选定文件路径及身份、实际 origin、模型类型、会话指纹和加载／显示结果。未接管模型返回 `model_id=null`、`adopted=false`，不创建受管 revision。
- 会话存在同名同类型模型时拒绝。装配另要求加载前会话没有任何零件或装配；枚举无法完成也拒绝。检查与加载在同一 Toolkit 通道内执行。
- 原生流程为完整路径检索、立即检查检索错误、核对模型、显示并激活。依赖沿用 Creo 当前搜索规则，不修改搜索配置。
- 装配检索不完整时报告明确失败及可能残留的会话对象；加载成功但显示失败也分别报告。无法取得具体缺件清单时明确标记未知。
- 不自动保存、覆盖、擦除、重命名或接管源模型。超时、断连或结果不完整沿用 `unknown_outcome`，保留证据，禁止自动重放。
- 复用现有单通道、busy 和幂等契约；新业务实现放包内，补齐任务分发、轮询摘要、源码指纹与打包覆盖。

## 3. 诊断与能力发现

| 条目 | 本轮改动 |
|---|---|
| FEAT-023 | `creo_capabilities` 新增 `detail/section/limit/cursor`，默认 compact；详情按工具、能力族、引用、种子、证据和运行身份分页 |
| FEAT-008 | 顶层明确磁盘打开、会话枚举、接管和装配检查的支持状态；同步工具说明及查询示例 |

| FEAT-006／008 | 空窗口接管返回 `NO_CURRENT_MODEL`，保留失败调用和 Toolkit 原码，提示查询会话模型 |
| FEAT-008 | 接管拒绝增加稳定原因、实际单位和可靠取得的依赖／健康信息；未知详情明确标记 |

capabilities 单页按现有序列化口径限制为 **32 KiB**，包含分页元数据；超大集合拆分，不静默截断。详情使用进程内冻结快照，600 秒过期，重启或失效 cursor 明确拒绝。同步修改默认返回结构变化的迁移指引。

毫米、依赖和健康准入保持现有边界；BUG-072 的单位／体积修复继续独立验收。本轮分项通过不代表这些既有大条目全部完成。

## 4. 验收计划

- **Python／协议**：覆盖数字版本排序、精确版本、中文及空格路径、非法文件、提交后文件变化、幂等重放、busy、同名冲突、未知结果和 compact/full 一致性。
- **能力输出**：验证默认及每页大小、完整遍历无遗漏、超大单项处理、错误 cursor、过期和服务重启。
- **本机 Creo 12.4**：验证零件和完整装配打开、缺件装配、显示失败、同名拒绝、非空会话装配拒绝；用几何不同的 `.1/.2` 验证精确版本选择。
- **原件保护**：开发者记录源文件及组件前后哈希、名称和保存版本；纯打开不以保存重载作为成功条件，接管续作回归仍执行原有保存重载要求。
- **WorkBuddy**：另备公开 MCP 黑盒提示词，只记录实际调用、任务终态、Creo 显示和公开字段，不要求读取源码或运行本地脚本。

执行统一检查、匹配 SDK 构建及新增针对性集成测试。原始 `asm_mx.asm.16` 尚未取得，其具体场景保持“待原环境复验”，不以本机样件通过替代。
