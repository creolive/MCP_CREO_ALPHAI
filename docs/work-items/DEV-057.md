## 剩余范围

1. **B：先复用，不重建。** 以 `tools/test_detail_feature_observation.py` 的 L 棱柱 + `round_concave` 场景为基线（模型、`base_operations`、`edge_at=[20,20]` 与解析 oracle 都已存在），补两件事：同一目标棱的 `surface`（face-pair）引用对照，以及负半径/无效边反例；只有原案载荷到手时才做原案回放。若需要单独入口，优先给该驱动加用例/参数（例如新增 `round_concave_facepair` 用例），**不新建独立脚本、不重造模型**。记录特征终态、应用组数、体积前后、目标棱几何与保存重载。仅当证实产品缺陷时另登记新 BUG ID（本卡不占号）。
2. **C**：把 spline 坐标驱动作为 [FEAT-010](FEAT-010.md) 子项定范围并冻结契约（点语义、开闭、切向/权重、容差、偏差可观测），未定前不删 schema 限制、不静默改 autodim。若实现，需覆盖创建/编辑/求解/保存重载与"偏差超限/不可测"两态。
3. **G**：取得原载荷后按"草图方向输入"（关联 BUG-045 调查）或"装配方向新输入形态"（FEAT-012）分流；矩阵侧的 1e-6 拒绝属现行正确契约，不写成 bug。

- 不实现 spline 坐标标注，不删除或放宽 schema 限制。
