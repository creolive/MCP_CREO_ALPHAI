## 共享接口基线（T00 固定，供 T01—T13 遵循）

本节落实用户已确认的总计划和派发表，描述 **0.7.0 的目标接口约定**；除注明“既有”者外，不表示 0.6.1 已公开或已通过验收。后续实现不得各自改写字段含义、另建同义工具或把未实现能力标为可用；需要改变共享契约时先回报集成负责人并同步本节及受影响任务。

### 1. 平面选择与局部帧（T03，供 T04/T05/T06/T08/T09 使用）

- `datum_plane.id` 是当前模型巡检 `datum_planes` 返回的基准平面**几何 ID**；`plane.id` 是需验证为平面的几何 ID；`surface.id` 沿用表面几何引用。特征标签沿用 `datum_feature`，特征 ID 与几何 ID 不互换，不跨模型猜测身份。
- 在同一个 `plane`/`datum_plane` 引用对象中，显式 `id` 与 `axis`、`normal`、`offset` 任一筛选字段同时出现即拒绝，即使值为默认 Z 或 offset=0 也不静默忽略。无 id 时保留既有几何筛选语义；axis/normal 的既有合法组合边界不在本轮暗改。
- Python 准入与 native 最终边界执行相同规则；ID 类型错误准入拒绝，不存在、非平面或歧义准确失败，不能回退默认 Z/XY 面。显式引用必须选中实际目标；加入干扰平面后仍一致。
- 草图结果回显实际解析的 `surface_id`、`origin`、`normal`、`u_axis`、`v_axis`；方向和位置来自原生对象，不能只回显请求伪装成查询结果。Right/倾斜面用 ID、surface、标签引用应得到同一物理帧。
- 纯 Z U 轴只要有效且位于面内即可使用；零向量或平行实际法向明确拒绝。T04 不改输入坐标、不放宽坐标回读阈值、不静默降级；T05 以实际帧验拉伸正负、对称总深和双向贯穿。免引用 `plane={origin,normal,u_axis}`、显式拉伸 `direction_vector` 不列入本轮新接口。

### 2. 操作结果与 revision（T02，各写任务共用）

对已受理且形成操作结果的计划，N 个输入对应 N 条有序结果，零基 `index=0..N-1` 与原输入一一对应，不能把请求回显另 push 一次。准入拒绝无新 job，不能补造已执行结果。既有原生分支、compact/full 和持久化 job 使用一致语义。

| 字段 | 固定取值 / 含义 |
| --- | --- |
| `execution_status` | `succeeded` 实际执行成功；`failed` 实际失败；`not_executed` 确认未执行；`unknown` 无法确认执行结果。 |
| `effect_status` | `committed` 最终持久化提交已确认；`rolled_back` 有实际回滚证据；`no_effect` 确认未产生写入效果；`unknown` 最终效果不能确认。 |
| 既有 `succeeded` | 仅在执行结果可确认时兼容保留；表示执行事实，不表示事务最终提交。未知或未执行不能填 true。 |

中途失败时，前面执行成功的项可以是 `succeeded` + `rolled_back`；失败项依真实执行/回滚事实填值，后面确认未执行的项为 `not_executed` + `no_effect`。无法证实回滚不能补 `rolled_back`，不能从作业 failed 或历史检查点存在推断效果。无材料变化本身不等于 `no_effect`；成功保存并推进 revision 的同几何快捷路径仍是已提交作业。

保留 `unchanged`、`native_geometry_verified`、`feature_id`、`file`、`metadata`、`size`、`material_removed_mm3` 等原路径专有字段；不以去重丢掉文件、尺寸或诊断。检查依赖结果条数生成身份的路径，不能因去重重命名已有对象。既有 `component_changes.status` 是独立的组件变更摘要枚举，不能直接覆盖为本表两个状态字段。

`unchanged=true` 仅用于已核验的同几何快捷路径；同值 `set_dimensions` 不新增此承诺。成功操作继续执行保存重载和约定 revision 推进；一次既有模型计划成功只提交一次 revision，失败按原事务/unknown 保护处理，不自动重发剩余操作。

### 3. 零件特征生命周期（T08，FEAT-036/027）

复用 `creo_execute_plan`，新增 `op="feature_state"`，`action="delete"|"suppress"|"resume"`，`targets` 为显式特征标签或非负特征 ID 列表；复用既有 `model_id`、`expected_revision`、单作业事务和回滚，不新增独立删除工具。

- 首批限受管 part/sheetmetal 的普通草图、基准、拉伸/回转及切除、组/阵列头。系统必需对象、非法单独组/阵列成员操作明确拒绝，组件删除不算此能力。
- 巡检给出依赖关系；targets 未覆盖受影响依赖时返回依赖清单并拒绝，原生执行前复核。调用者必须显式列出全部受影响对象，不自动级联。
- 删除保留标签墓碑，旧别名和历史引用不能重新指向其他对象；抑制保留身份，resume 仅针对已抑制对象。每目标返回真实前后状态和效果。
- 有意抑制集合须登记并参与健康、保存重载、回滚比较；只接纳明确记录且实际一致的抑制，不能整体放宽失败/抑制检查。后续合法编辑仍须可用。

### 4. 约束快照回放计划（T09，FEAT-049）

新增只读 `creo_plan_assembly_rebuild(snapshot_id, component_mapping, reference_mapping)`；输入冻结快照与显式映射，输出供既有 `creo_execute_plan` 使用的 `operations` 及绑定的源身份。规划调用不加载、不收养、不修改原装配或源件、不生成写作业/revision，也不建立额外 Toolkit 连接。

- 快照扩充双侧引用身份、方向、偏移单位、`replayable`/`reason`；区别新旧快照版本、过期和不完整证据。component_mapping 显式表达 occurrence 到目标组件/源 model_id，reference_mapping 显式表达源引用到目标引用，不能只凭 item_id 跨模型推断。
- 装配侧引用扩展为明确指向同层兄弟组件标签/ID；计划必须先插入全部组件，再设置约束。首期限单层和既有六类型 `mate`、`align`、`mate_offset`、`align_offset`、`insert`、`csys`；既有 fixed/default 放置按真实语义单列，不拿 fixed 代替无法回放的约束。
- 计划绑定源件 revision/摘要，提交及原生使用前重新核验；快照十分钟有效期不是长期写入授权。未知类型、缺映射、不可还原根引用、过期/旧证据、源件变化、嵌套回放均明确拒绝。超过既有 200 操作上限拒绝，不拆成多个事务。
- 现有目标模型失败整批回滚；验收需要改变驱动条件后的真实随动、双侧方向/单位和保存重载，初始 transform 相同不够。FEAT-050 公共比对、嵌套、新约束类型不在本批。

### 5. 只读会话健康证据（T10，BUG-078）

公开状态增加 `session_health`，`status` 固定为 `unknown`、`suspected_damage`、`no_failure_observed`，附观测时间、来源会话身份、已有保存/连接事实和 `next_steps`。先在**不触发新 Toolkit 调用**的状态路径公开，再复用 session_status 已完成结果；不得为了查询健康主动连接或保存。

- 无证据、身份不明、证据过期或会话已变化为 `unknown`；已有相关损坏迹象为 `suspected_damage`；近期没有观察到失败为 `no_failure_observed`，不能改称“健康保证”。连接成功不证明下次 Backup 必成功。
- 只读查询不改模型、revision、未知结果保护或恢复历史。繁忙、权限未知、旧失败与新会话必须如实表达；会话重建使旧证据失效，不能沿用旧成功。
