# BUG-112：曲面偏置源面积初始化丢弃 ProQuiltInit 返回码

类型：缺陷。优先级：P1。状态：已交付 **0.15.0**（初始化失败不再进入面积测量、`source_area_status` 回执与 C4552 编译门禁；40×20/±5 mm 实机基准与量纲/已有实体保护仍未验证）。目标版本：0.15.0（已发布）。

来源：DEV-069 报告 B §4.1；MSVC C4552。本地 0.14.0 / `7002575` 的 `native/surfaces.cpp:168` 仍为 `if (!ProQuiltInit(...); quilt)`，真正条件仅检查指针。

## 目标与范围

显式检查 `PRO_TK_NO_ERROR` 且 handle 有效后才测面积；保留原始 Init/面积测量码与不可用原因，失败不得伪造面积/距离。把 C4552 纳入原生自有源码编译失败条件，第三方与 SDK 不做全警告升级。关联 FEAT-039/Q03 的偏置计量风险，返回码修复不代表已有实体/非平面源计量已可靠。

## 验收与环境

原生 stub 覆盖 code!=0 但 handle 非空、code=0 但空、code=0 且可测三个组合，前两者不调用测量；SDK 构建消除 C4552；已有 40×20/5 mm 双侧基准仍应保存重载通过。MSVC/本机 Creo 12.4 匹配 SDK；Creo 10 新运行证据本轮无。详见计划 R01，遵守 BUG-001，不做实机故障注入。

`source_area_status` 键（与既有 `source_area_mm2` 并存，旧键语义不变）：

- `available`（bool）：仅当面积真的测到才 true。
- `init_code`（int）：`ProQuiltInit` 原始返回码。
- `query_code`（int|null）：实际执行过的面积查询码；未查询（Init 失败或 handle 为空）为 null，不写 0。
- `reason`（string|null）：Init 失败 `quilt_init_failed`；Init 成功但 handle 空 `quilt_handle_missing`；测量失败沿用 `MeasurementOutcome.reason`；无原因时 `source_area_unavailable`。
- 投影规则：`available=false` 时 `source_area_mm2` 与 `measured_offset_distance_mm` 一律 null；`available=true` 时非有限距离也归 null。畸形块降级为 `source_area_status_missing`。

三种 stub 组合（`tests/native/test_surface_measure_guard.cpp`）：

1. `init_code=-1` + handle 非空：`quilt_gauge_ready` 为假，测量调用计数 0。
2. `init_code=0` + handle 为 `nullptr`：为假，测量调用计数 0。
3. `init_code=0` + handle 有效：为真，测量调用计数 1；另断言任意非零码带 handle 也不测量。
