# BUG-095：任意平面草图 origin 拒绝缺诊断

日期：2026-10-31。类型：缺陷。优先级：P2。状态：待复现（外部反馈）。目标版本：未排期。

来源：[F3 原件](../validation/feedback-0.9.0-2026-10-31/manifest.json) 问题 5；[逐章映射](../validation/feedback-0.9.0-2026-10-31/MAPPING.md)。关联 FEAT-008、总计划 P07。

## 现象与待验证根因

报告给出的草图 origin 到支撑面偏差约 `1.07e-4 mm`，被拒时没有距离、平面方程或阈值诊断。当前阈值为 `1e-6 mm`；是否同一模型/同一支撑面、实际有符号距离和错误路径仍待复现。不能据一份反馈改成通用 `1e-3 mm` 或自动移动用户原点。

## 范围与验收

P07 保持 `1e-6 mm` 判定阈值，拒绝时返回由实际支撑面计算的有符号/绝对距离、归一法向、平面常数和阈值；可给建议投影点但不执行投影。覆盖省略 origin、面上、阈内、阈外及正负偏差。

Windows x64 / Python 3.12+ 专项单元回归；本机 Creo 12.4.0.0 / 匹配 SDK / MSVC 在会话准入后核真实支撑面和错误数值、非法例无特征/revision 变化、正确 origin 续编及保存重载。Creo 9/10 本机原生范围未验。P00 只登记，不宣称修复。
