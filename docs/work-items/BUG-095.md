# BUG-095：任意平面草图 origin 拒绝缺诊断

日期：2026-10-31。类型：缺陷。优先级：P2。状态：离线已实现（P07），实机验证待排期。目标版本：契约新增属 MINOR（0.11.0 候选）。

来源：[F3 原件](../validation/feedback-0.9.0-2026-10-31/manifest.json) 问题 5；[逐章映射](../validation/feedback-0.9.0-2026-10-31/MAPPING.md)。关联 FEAT-008、总计划 P07。DEV-053 post0100 批次 P07 窗口离线交付。

## 现象与待验证根因

报告给出的草图 origin 到支撑面偏差约 `1.07e-4 mm`，被拒时没有距离、平面方程或阈值诊断。当前阈值为 `1e-6 mm`；是否同一模型/同一支撑面、实际有符号距离和错误路径仍待复现。不能据一份反馈改成通用 `1e-3 mm` 或自动移动用户原点。

## 范围与验收

P07 保持 `1e-6 mm` 判定阈值，拒绝时返回由实际支撑面计算的有符号/绝对距离、归一法向、平面常数和阈值；可给建议投影点但不执行投影。覆盖省略 origin、面上、阈内、阈外及正负偏差。

Windows x64 / Python 3.12+ 专项单元回归；本机 Creo 12.4.0.0 / 匹配 SDK / MSVC 在会话准入后核真实支撑面和错误数值、非法例无特征/revision 变化、正确 origin 续编及保存重载。Creo 9/10 本机原生范围未验。

## 输出契约（P07 实施设计冻结，2026-10-31）

仅当显式字典平面带 `origin` 且到实际支撑面有符号距离超过 `1e-6 mm` 时，失败操作记录携带 `sketch_origin_diagnostics`：

- `status`：固定 `"origin_outside_support_plane"`。
- `distance_to_plane_mm`：有符号距离的绝对值。
- `signed_distance_to_plane_mm`：`n·(origin - 支撑面 origin)`，n 为草图帧实际使用的归一支撑法向（显式平面分支取几何法向本身，不做命名平面的朝向翻转）。
- `origin_tolerance_mm`：固定 `1e-6`。
- `support_plane`：`{normal:[nx,ny,nz]（归一）, constant_mm:n·支撑面 origin}`（平面方程 `n·x = constant_mm`）。
- `requested_origin`：请求原点原样回显。
- `suggested_origin`：请求原点到支撑面的显式投影（建议值，不是已执行的修改；省略 origin 或阈内原点不产生本块、不吸附、不投影）。

错误传递路径（冻结）：native `sketch_frame` 计算证据 → `stage_operation_result` 暂存 → 抛出确定性消息（前缀 `Sketch origin is outside support plane: signed distance ... exceeds the 1e-06 mm tolerance; see sketch_origin_diagnostics`）→ `execute_operation` 失败记录并入该块（`succeeded=false`/`execution_status=failed`）→ 作业级 `report.message` 为该消息。Python 侧 `operation_results.annotate_sketch_origin_diagnostics` 只做形状与一致性校验（有限数、`|signed|==distance`、法向单位、非单位法向降级 unknown），缺失块保持缺失、绝不从请求回填。结果新增字段属 MINOR。
