## 问题或目标

报告的实测事实链（Windows 10 x64 / Creo 10.0.0.0 / VS 2022 17.14.40）：`native/blend_sync.cpp` 在 0.3.1 与 0.3.2 逐字节相同（sha256 `c2c6d4a6…`），但 0.3.1 与 0.3.2 编出的 DLL 副本不同（`96430578b3ac85f0`、`0e46ef9d76575785`），**同机同工具链连续两次编译也不同**（`0e46ef9d…`、`c6dbf37b5335d7a6`），四个副本大小均为 3 384 832 B。

与 0.3.1 引入的 `prepare_callback()` 叠加后：DLL 按 sha256 建不可变副本目录，`protk.dat` 的 `exec_file`/`text_dir` 指向该目录，于是**每次原生重编译都会产生新哈希、新目录、新 `protk.dat`，使用户在 Creo 辅助应用程序中的既有注册条目指向失效路径**，需要再次人工注册并启动。报告方本机 `build/blend_callback/` 已累积 3 个 sha 目录（其中 2 个为重编译噪音），目录名只有哈希，没有"当前有效"标记；`blend_sync_build.json` 记录的哈希与当前 DLL 不匹配时，下次 `build_native()` 会再次更换目录。

次要问题：副本哈希与登记不一致时只抛 `Immutable Blend callback copy was changed; inspect it before setup`，报告称外部流程（CI 或手工编译）只重编 DLL 时会出现"登记 A、实际 B"的不一致态且无自动修复路径。

根因未验证：报告提出的方向为 PE 时间戳/校验和（未开 `/Brepro`）、PDB 与对象文件绝对路径嵌入等。待验证项：本仓库实际构建参数、`protocol: 2` 字段与注册路径的耦合方式、目录清理的安全边界。

## 范围

包含：核实回调 DLL 的构建产物、副本目录、`protk.dat`/`blend_callback_setup.json`/`blend_sync_build.json` 的生成与判定逻辑，以及升级、重编译和并存安装下的注册有效期契约。候选方案（固定注册目录 + 清单、过期 sha 目录清理、`registered_dll_stale` 类告警、`/Brepro` 可复现构建）需先核实再选型，不因报告建议直接实施。

不包含：代替用户在 Creo UI 注册或修改其加载器安全策略、自动加载/签名 DLL、改变未签名回调的既有约束；不承诺消除用户侧一次性注册成本，也不把"自动注册"作为目标。

## 2026-10-21 IMPROVEMENT 计划实施：指纹稳定化与旧缓存兼容

按[完善计划](../development/CREO10-0.4.1-FEEDBACK-IMPROVEMENT-PLAN-2026-10-20.md)实施本轮主要修复（第二份反馈 §2 归档 [feedback-0.4.1-creo10-build-2026-10-20](../validation/feedback-0.4.1-creo10-build-2026-10-20/report.md)）：

- **保留 `json.hpp` 于依赖清单**（loader/payload 实际使用，移出会错误复用旧 DLL）；构建指纹改按 CRLF→LF 归一化内容计算（`creo_mechdog.build_fingerprints`，算法标识 `sha256-repo-lf-v1`），SDK 头/有效配置/二进制 SHA256/发布附件保持原始字节。
- **区分规范化指纹与物理世代目录键**：缓存新增 `algorithm`+`generation_key`，`blend_callback_setup.json` 的 `loader_fingerprint` 仍为实际目录键。旧缓存按原始/LF/CRLF 全组合重算原算法，精确命中且不可变镜像 SHA 正确才复用原世代（注册路径不变）；无法证明等价重编并说明原因。
- **元数据先发布后写缓存标记**（逐文件原子、`source.sha256` 原子写），中断不误报成功。
- 新发现并修复：非确定性重编回到历史指纹时世代目录被占用导致构建死锁，引入派生键 `<指纹>-<sha256[:12]>` 并存，历史不可变副本不动。

验证：8 项专项单测+全套 469 项+dev_check 通过；实机从 0.4.3 真实缓存出发完成迁移复用（`695fdd07…` 世代保留、仅 worker 重编一次）、json.hpp 行尾全量翻转零重建、真实内容变化重建、往返切换派生键共存等场景，见[验证记录](../validation/DEV-027-030-IMPROVEMENT-2026-10-21.md)。同源码重编译的**二进制可复现性**与 payload 目录累积盘点/回收仍归本卡未完成范围；0.3.4 外部解耦正例继续有效。
