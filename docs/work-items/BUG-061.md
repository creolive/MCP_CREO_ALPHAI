## 报告现象（0.3.3 实测，0.3.5 未复测）

草图 `plane` 传字典形式（如 `{reference:…, offset:非零}`）时被拒；0.3.5 轮未复测。使用者目前只能先 `creo_datum_plane` 建面再按 label 引用。

## 待核对

- 字典平面 + offset 的预期语义：是引用已有面，还是隐式新建偏移面（FEAT-008 要求说清的问题）；
- 拒绝时的报错是否提示替代路径（先建 datum_plane 再引用）；
- 与 BUG-031（mirror offset）是否同一解析路径，修复时一并核对，不各自放宽。

## 范围

仅草图 plane 字典输入的 offset 分支与报错；不改变 XY/XZ/YZ 简写与显式 datum_plane 引用的现有行为。
