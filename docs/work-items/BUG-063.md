# BUG-063：axis_pattern 非原点轴上实例几何静默错误

日期：2026-10-18。类型：缺陷。优先级：P1。状态：待复现。目标版本：未排期。

来源：外部 0.3.5 能力边界反馈 P2（Creo 10.0.0.0 / release 42，虹膜机构重建任务），见[原件](../validation/FEEDBACK-0.3.5-CAPABILITY-2026-10-18.md)。关联 [BUG-065](BUG-065.md)（datum_axis 两平面求交错误，本项根因之一）、[BUG-035](BUG-035.md)（dimension_pattern 另一问题）。

## 报告现象（外部实机，体积量化）

小齿轮（盘心 (0,−0.092)）绕 (0,−0.504) 的 +Z 轴阵列：

- `creo_axis_pattern` count=10/inc=36°：体积仅再降 179.58 ≈ 2 个槽，期望 795.89（9×88.43）；`status: succeeded`、features 出现 10 个 instance（seed + id 152–160），**多数实例被转到厚度方向之外、几乎不切材料**，符合旋转轴非 Z 向的推断。
- 另一模型 count=2/inc=36°：仅切除 18.35（期望 88.43）。
- 对照组：**过原点 Z 轴完全正常**——齿形摩擦片 40×9°（3061.56=78.50×39）与 5×72° U 槽（1792.57=448.14×4）均精确。
- 三种非原点轴构造（datum_plane id+axis 组合 ×2、label+axis）全部产生错误几何且 succeeded 无告警；唯一可行构造是**柱面取轴**（临时凸台柱面 → 轴正确，最终齿轮 1490.7023 与目标 1490.8 偏差 −0.0066%）。

**结论（待本机核实）**：`creo_axis_pattern` 仅在轴过零件原点时可靠；非原点轴静默产出错误几何。

## 待核对与修复方向（反馈建议，供参考）

1. 核对非原点轴时实例变换矩阵的构造路径（是否按过原点假设简化）。
2. 阵列后自校验：`material_removed_mm3` 与 (count−1)×seed 去料量偏差 >20% 时报 warning，不静默 succeeded。
3. `axis` 参数支持显式 `{origin:[x,y,z], direction:[x,y,z]}`，绕开基准轴构造（关联 BUG-065）。

## 范围
