# BUG-062：update_sketch_geometry 不支持 centerline，回转类草图不可就地编辑

日期：2026-10-18。类型：缺陷。优先级：P1。状态：已修复（验收中；2026-10-23 外部 Creo 9 通过子项已补录，在轴构型另立 BUG-082，其余范围按卡）。目标版本：下一未发布 PATCH。

来源：外部 0.3.5 曲面链路反馈 §2.1（Creo 10.0.0.0 / release 42 / stdio），见[原件](../validation/feedback-0.3.5-surface-2026-10-18/report.md)。关联 [BUG-030](BUG-030.md)（同一工具的再生失败问题，彼此独立）。

## 报告现象（外部实机复现，job 085e56a792c5473a82fdff1b7340b118）

对一张含 centerline 的回转草图调用 `creo_update_sketch_geometry`，两条路径都失败：

- 只传 arc + polyline（不含 centerline）：`failed_stage: execute_update_sketch_geometry`，`In-place edit must retain every named sketch entity`；
- 把 centerline 一起传入：schema 层直接拒绝，`In-place editing supports line, polyline, rectangle, circle, arc, ellipse and spline`。

矛盾点：`create_sketch` 文档明确要求 *"For revolve include one centerline"*，而就地编辑不支持 centerline——**所有回转类草图天生不可就地编辑**。外部本次为把 R8 球心从 −25 移到 −31，被迫把 30 特征链路整模重建两遍（约 12 个 job）。

## 待核对与修复方向（反馈建议，供参考）

1. 把 `centerline` 加入 in-place 支持的实体类型（构造线，重算成本低）；
2. 或 `update_sketch_geometry` 增加 `preserve_unlisted: true`，未列出的实体原样保留——更通用，也缓解"只想改一条边但要传全量"的体验问题。

先本机复现两条拒绝路径并核对 schema 与实现的允许集合，再选最小方案；不得借机放宽"必须保留全部命名实体"的保护语义本身。

## 范围

仅 `update_sketch_geometry` 的实体类型集合与保留规则；不改变 `create_sketch` 的 centerline 要求、命名实体校验和失败回滚行为。修订后 BUG-030 的"换成相同几何也再生失败"仍按其自身条目处理。

## 实现与证据

2026-10-18 仅登记。未复现、未修改实现。原始证据见反馈原件 §2.1 与 job `085e56a7…`。

### 2026-10-22 修复与实机验收

[批次记录](../validation/BATCH2-EDITING-2026-10-22.md) 第 1 节。根因即登记的两条路径之二：Python schema `SketchGeometryOp.supported_entities` 集合缺 `centerline`（原生编辑器已有 `PRO_2D_CENTER_LINE` 分支，零改动）。修复=集合与错误消息、工具说明同步；新增单测 4 项。实机：R5→R6 回转草图独立工具与计划入口各两轮（体积 500π/3→288π、bbox 三向 12、草图/回转 ID 保持、rev 仅 +1、保存重载通过）；缺实体/改名/改类型三负面路径准确拒绝，失败后可继续编辑。`preserve_unlisted` 与约束扩展按范围不做。

### 2026-10-23 最终复验（会话重启后）

独立重跑生成脚本（新隔离模型，不在旧失败模型上重提）：两入口回转草图 R5→R6 均通过（体积 523.599→904.779 mm³、revision 1→2、`saved_file_reloaded_and_verified=true`、特征身份保持）；缺实体／改名／改类型三负例拒绝；`post_failure_plan_edit` 修订 3、体积回到 523.599。报告 `build/editing-closeout/terminal-8655b8b6218045fbb00aabe5822bfb03/verify3.json` 及同目录终态清单。同轮（最终格式化源码）九项编辑专项 9/9、general_core 7/7、新增实体分支核验（含 centerline+circle 同几何重复提交）全部通过，证据见 [BUG-030 收口](../validation/BUG030-CACHE-CLOSEOUT-2026-10-22.md)。
