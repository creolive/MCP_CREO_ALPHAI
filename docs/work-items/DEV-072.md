## 目标与已证实现象

先核已完成事项，避免重做 origin、edge_geometry、BUG-115 和长轮询。反馈指出：几何兜底通过时旧板厚 API 字段仍 false/null 且文档未解释；几何选边失配无最近候选；空装配预览报 failed；远端附件检查只依赖 gh；主台账三行与已发布子项不一致。

源码核对与本地夹具复现分别记录，外部报告的几何结果不算本机新验收。历史附件替换与摘要冲突为报告方事实链，本轮不推断替换原因、不覆盖旧附件或历史验证原件。

## 范围与设计

1. 板厚采用报告建议的兼容方案②：保留 API 原始字段；补明确 scope/reason/fallback，权威判据为有来源的 thickness_validation，不把几何值冒充 API 读数。
2. edge_geometry 保持严格唯一匹配与原容差；失配时给有界最近候选及端点误差；不自动吸附被折边改变的拓扑。
3. 空装配确认为无几何时与空零件统一 skipped_no_geometry；查询失败沿原截图路径处理，不据此宣称无几何。
4. DEV-070 的附件检查增加标准库 GitHub API 下载备用路线；网络只在显式 --tag 检查时发生；离线单测 mock 网络。
5. 修正 DEV-070 / FEAT-007 / FEAT-039 台账及补逐 ID 人工核对规则。按既有发布规范不新造台账自动发布工具。
6. 本轮全量检查发现旧 UDF 输入测试与非法名称测试未隔离 `admission_holder` / `toolkit_lock`，真实会话 busy 时先抛 ToolkitBusy。仅修测试夹具，显式 mock 通道占用查询/锁并断言不启动进程；不更改产品准入顺序或实际通道状态。

本轮禁止连接 Creo、Toolkit、启动或结束 Creo、改注册/保护、构建或替换共享执行器。钣金附着增料、同段共享角部、格栅/百叶成形、miter/end_trim 实际去料与旧版本远端附件复核留待独立环境。新增原生代码只标离线实现、未编译/未实机。
