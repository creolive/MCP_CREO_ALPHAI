# BUG-102：倒角+圆角边界面 10° 拔模由成功变 `-1`，`flip` 入参与回显不一致

日期：2026-11-02。类型：缺陷。优先级：P1。状态：部分复现（`flip` 请求/生效歧义已随 0.11.2 修复；`-1` 方向依赖失败未在本机复现；2026-11-05 已补跑带 chamfer+R3 的成功路径两向）。目标版本：0.11.2（诊断已交付，定因未做）。关联 [FEAT-051](FEAT-051.md)（`draft_geometry` 回报已交付）、[DEV-060](DEV-060.md)。

## 来源

- 原件：[0.10.0 第十轮反馈 F02 §五 N1](../validation/feedback-0.10.0-2026-10-31/originals/20261031_CREO_v0.10.0_端点焊接诊断已补齐但仍不可焊_draft方向取反静默失败.md)。
- 环境：外部 Creo Parametric 10.0.0.0、MCP 0.10.0。

## 现象（报告方实测，本仓库未复现）

40×30×10 方块（体积 12000）先 `chamfer size=2`、再 `round R=3`，然后对侧面 `surface 69` 做 10° 拔模：

| 调用 | 0.9.0 | 0.10.0 |
| --- | --- | --- |
| `angle=10, flip=false` | succeeded，+264.19 mm³ | `ProFeatureWithoptionsCreate=-1`，rolled_back |
| `angle=10, flip=true` | succeeded，−264.79 mm³ | 同样 `-1` |
| `angle=10, flip=false` + `pull_direction={surface 69}` | — | 同样 `-1` |
| `angle=5, surface 67（无倒角面）, flip=false` | — | succeeded，+169.759 mm³，回显 `draft_geometry.flip: true` |

失败信息只有 `Toolkit call ProFeatureWithoptionsCreate failed with code -1 during execute_draft`，未区分“几何不可行（与倒角/圆角冲突）”与“引用错误”。

同一成功例暴露签名问题：入参 `flip=false`，回显 `draft_geometry.flip=true`，调用方无法判断该值是“请求被翻转后应用”还是“实际生效值”。

## 当前实现状态（0.11.1 只读核对）

- `native/advanced.cpp:224-256` 的 `generic_draft` 无“加料即拒绝”守卫；FEAT-051 期间新增了 `PRO_E_DRAFT_TWEAK_OR_INTERSECT=PRO_DRAFT_UI_INTERSECT`、`PRO_E_DRAFT_EXTEND=PRO_DRAFT_UI_NO_EXTEND`、`PRO_E_DRAFT_SPLIT=PRO_DRAFT_UI_SPLIT_NONE` 三个元素，属 0.9.0→0.10.0 之间最可疑的变量。
- `draft_geometry.flip` 读的是创建后特征树里的 `PRO_E_DIRECTION_FLIP` 实际值（`advanced.cpp:178-184`），与请求值不做区分；`requested_flip`/`effective_flip` 全库 0 命中。
- 工具描述（`server.py:1543-1549`）已写明回读的是“实际”值、且加料可由 `material_delta_mm3` 符号识别，但没有两个字段的对照。

## 范围

包含：

1. 用最小 A/B 对照定因：当前元素树 vs 去掉 `EXTEND/SPLIT/INTERSECT` 三元素的元素树，在“带 chamfer+round 的侧面”上做 10° 拔模；区分“元素树收紧导致无法延伸”“引用选择错误”“几何本身不可行”。
2. 按结论落地：要么修复（恢复可行构造），要么明确拒绝并给出可执行提示（减小角度 / 先删圆角倒角 / 改引用），失败信息必须分类。
3. `draft_geometry` 增 `requested_flip` 与 `effective_flip`（保留现有 `flip` 不动，避免破坏既有契约），并在工具描述说明差异。

不包含：

- 不实现“自动删除冲突圆角/倒角再拔模”的改写能力。
- 不改变 `material_measurement` 与既有 `material_delta_mm3` 语义。

## 2026-11-02 离线实现（定因未做、实机未跑）

- **签名歧义已解**：`native/advanced.cpp` `draft_geometry_json(ProFeature&, bool requested_flip)` 新增 `requested_flip`（原样回显入参）与 `effective_flip`（特征树实读，读不到为 null），既有 `flip` 保持不变以免破坏 0.11.x 契约；`server.py` 工具描述同步说明差异。原生源码断言锁定 `draft_geometry_json(f, op.value("flip", false))`，防止用树值冒充请求值。
- **失败可解释（不猜结论）**：`generic_draft` 在 `create()` 抛错时 stage `draft_failure{api, requested_flip, angle_deg, surface_count, element_errors{total,truncated,sample≤20}, classification, note}`，`classification` 只在“有无内核元素诊断”之间二分（`kernel_element_error` / `no_element_evidence`），不再声称“几何不可行”；`note` 给出下一步（减小角度 / 先删相邻圆角倒角 / 用 `creo_inspect_model` 重读面 ID）。原始 Toolkit 异常原样重抛，`root` 在失败路径释放。
- **A/B 待跑**：`tools/test_draft_regression.py` 冻结夹具（40×30×10、chamfer 2、R3、10°）与四个单变量变体（`A_current`、`B_no_extend`、`B_no_split`、`B_no_intersect`），并输出实机步骤；离线只校验“当前树仍带三个 flag + 失败回执字段齐”，`live_stage=not_run`。
- 证据：`tests/unit/test_draft_observation.py` 与 `test_detail_feature_observation.py` 共 54 项通过；驱动 exit 0，报告 `build/bug102_draft/20261102T164259_0000a9bd/report.json`（SHA256 `593D5411342F47A25D38CC5F548491AC573EE8FD1B9617883BFE474D2809922A`，40 777 B）。
- **原生构建**：`bridge.py build` exit 0（2026-11-02，`build/source.sha256=ffe75d9b…`）；`dev_check --work-item R10` 单元 2 130 项 0 失败。
- **2026-11-02 本机 Creo 12.4 实机**：40×30×10 素面侧边（surface 65）、中性面底部（surface 53）、`angle=10`、`flip=false` → **成功**，`draft_geometry.requested_flip=false`、`effective_flip=true`、`flip=true`、`material_delta_mm3=+264.490471`（与报告方 0.9.0 的 +264.19 同向）。即**“入参 false 回显 true”的歧义已复现并被新字段解释**，而报告方 0.10.0 的 `-1` 在本机未复现。
- **仍未定因**：带 chamfer+R3 的 10° 失败与元素树 A/B 未执行（需按 `tools/test_draft_regression.py` 的变体重建执行器）；本卡保持“部分复现”，不记“已修复”。
