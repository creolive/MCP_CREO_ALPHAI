## 2026-10-28：T08B 计数语义定稿（离线实现，数值待实机）

归 [DEV-051 T08B](../development/DEV051-T08B-ACCEPTANCE.md)。分支 `codex/dev051-feedback070`，基线 `0b26c66efd11a80826492b3c4dfb240a798b0a32`；未连接 Creo，`source_fingerprint=b96f513243bdabf6e5a422db0fdb0d4e176dc7feee7b4adaba5747fd850aaabb`。

枚举核对（本机 Creo 12.4 Toolkit `ProSolidBody.h`）：`NONE=-1, MISSING=0, CONSUMED=1, NO_CONTR_FEAT=2, NO_GEOMETRY=3, ACTIVE=4`。因此履带报告“state=3 和 4 各一”是**一个 NO_GEOMETRY 记录 + 一个 ACTIVE 材料体**，不是两个实体；旧输出对非 ACTIVE 记录不写 `has_geometry`/`bbox`，调用方无法分辨“没有这个键”与“测得为空”，这是“幽灵 body”观感的直接来源。负 ID 与无 bbox 都不构成删除理由。

定义：`counts.bodies` 保持原义 = `bodies` **记录**条数（含非 ACTIVE、无几何、负 ID 记录），由 `inspection_summary()` 计算，语义未替换。新增原生 `body_counts{objects, records, active, with_material, without_material, counts_meaning}`，`with_material` = ACTIVE 且 `surface_count>0`；装配为 `null`（不是 0）。逐体新增 `state_name`（未知报 `"unknown"`）、ACTIVE 体的 `surface_count`/`material`/`bbox_query_code`，非 ACTIVE 体显式 `material=false`、`has_geometry=null`。

未做的：没有硬减 1、没有按 ID 正负或 bbox 缺失删记录、没有新增清理、没有改动 `native/geometry.cpp` 的 `active_body()`/`remove_empty_body()`（复核后无需改；既有清理仍只在“恰好一个 ACTIVE body”时触发）。`counts.bodies=2` 与 `body_counts.with_material=1` 现在可同时成立且各自可解释。

未关闭理由：0.3.0 与履带原 job/native JSON 未交付，普通实体、薄钣金 185×232×1、报告厚壁 9 957 440 三类件的真实计数、`id=-5778` 记录重放、sweep(add) 2→1 的实际状态变化均待实机；材料归属的真实数值未取得前不写“已修复”。
