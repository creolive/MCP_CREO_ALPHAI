## 现象与待核实归因

外部 Creo 10 / 0.3.2 报告：约 2807～3201 面的模型，两操作作业耗时 552～644 s，request.json 约 5.6 MB、native.log 约 2.8 MB；报告认为重复 resolve/inspection 主导耗时，连接/前置核验约 90～120 s、收尾约 120 s。它没有随附分阶段计时与原生日志，不能把这些归因或“每轮廓 10～15 s”当作现版本性能基线。

## 范围与实施

1. 在隔离目录固定小/中/大模型及相同操作，记录连接、基线核验、引用解析、几何修改、快照、保存、重载、结果登记的耗时、调用次数和文件字节量；真实模拟件与履带报告分开标识。
2. 找出重复枚举的实际调用方与用途，选择按明确变更边界失效的查询复用/局部解析/日志分级，不先假设可以用特征局部几何替代完整基线核验。
3. 建立模型修改、重排、删除/恢复、参数编辑、重载、跨作业/会话时缓存失效规则；不复用过期 ID 或旧几何，不用当前模型快照验证它自身。
4. 与 FEAT-023 拆分体积问题：本项验证内部计算/序列化和耗时，FEAT-023 验证 MCP 返回的 UTF-8 字节与分页契约；与 FEAT-033 拆分预算，增加上限本身不算性能修复。
