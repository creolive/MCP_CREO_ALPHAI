# DEV-070：四附件校验接入打包与发布验收

类型：工程整理。优先级：P2。状态：已交付 **0.15.0**（四附件闸门与 LF sidecar 接入打包/本地核对；发布后远端四附件核对见发布记录）。目标版本：0.15.0（已发布）。

来源：DEV-069 报告 B §4.3/§4.4；关联 DEV-045（已完成的人工清单/远端检查不重开）、DEV-061（种子摘要）、DEV-062（版本文档）。

## 目标与范围

复用 `tools/check_release_assets.py::validate_directory(directory, version)`，打包后四附件缺失/错名/摘要不符必须失败；源码/种子 sidecar 固定 ASCII/LF。单元 CI 只做离线夹具，适用打包验证在已有打包流程执行；另由显式发布/发布后流程检查真实上传附件，不能称离线 CI 能证明上传齐全。

默认 --tag 无 gh/下载失败时给出 --dir 的可操作降级，不静默忽略远端失败。API 下载备用路线作为后续可选增强，首次交付不要求新网络依赖或重写自动发布。

## 2026-11-06 离线实现（R08，无 Creo、无网络）

改动文件：

- `src/creo_mechdog/release_integrity.py`（L54-L124）：新增 `expected_assets(version)`、`read_sidecar(path)`、`write_sidecar(path, digest, archive_name)`、`validate_asset_paths(paths: list[Path], version: str) -> list[str]`、`validate_directory(directory, version)`。`validate_directory` 仅枚举目录条目并委托 `validate_asset_paths`，四附件固定文件名不变。
- `tools/check_release_assets.py`（L1-L100）：删除本地重复实现，改为从包内导入 `expected_assets`/`read_sidecar`/`validate_asset_paths`/`validate_directory`（保留同名兼容导出）；`--tag` 下 gh 缺失或下载失败转为 `RuntimeError`，打印含 `--dir` 的降级命令并以 2 退出；`--dir` 成功输出 `local_verified: four assets present; both sidecars match (version ...)`。
- `tools/package.py`（L13-L18、L131-L164）：sidecar 改由 `write_sidecar` 写 ASCII+LF；种子 sidecar 缺失由 WARNING 改为报错并以 2 退出，附 `tools/package_seeds.py --output` 生成命令；打包完成后用 `validate_asset_paths` 校验源码 zip、种子 zip 与两个 sidecar 的实际路径，失败以 1 退出；`--stage` 仍为展开源码 staging。
- `tools/package_seeds.py`（L13-L19、L94-L95）：改用 `write_sidecar`。
- `tests/unit/test_release_assets.py`：新增四路径分布在不同目录、目录内额外临时文件、版本/摘要不符、sidecar LF 字节、旧 CRLF 兼容、gh 缺失/下载失败降级、打包入口缺种子 sidecar 非零退出与四件齐全成功。
- `tests/unit/test_release_integrity.py`（L45-L50、L252-L284）：打包正例夹具改用规范四附件名并生成种子 sidecar，配合新闸门。

闸门与行尾：

- 四附件固定名：`MCP_CREO_MechDog-<version>-source.zip` 与其 `.sha256`、`MCP_CREO_MechDog-<version>-seed-library.zip` 与其 `.sha256`。
- 生成侧使用 `Path.open("w", encoding="ascii", newline="\n")`；测试用 `read_bytes()` 断言 `b"\r" not in payload` 且以 `b"\n"` 结尾。读取侧 `splitlines()` 继续兼容旧 CRLF sidecar。
- 校验项保持：缺件、多余件、sidecar 文件名不匹配、摘要不符、sidecar 非 ASCII 或非单行。
