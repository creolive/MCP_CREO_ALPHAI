### 变更

- 新建 `src/creo_mechdog/release_integrity.py`：`validate_release_inputs(root, seed_archive) -> dict[str, object]`（失败抛 `ValueError`）、`validate_seed_archive()`、`trusted_seed_package()` / `trusted_seed_archive_digest()`、`seed_library_files()`、`read_version()`、`readme_versions()`。
- 新建 `docs/seed_package.json`：本版本受信种子摘要记录（`compatible_server_version` + `seed_archive_sha256`），是唯一的"期望摘要"来源，不从待验证 ZIP 自身读取。
- 根 `seeds.py`：`install_seed_library(archive_file=...)` 改为先经 `validate_seed_archive()` 再写目标；新增 `expected_archive_sha256()` 摘要入口。目录安装路径保持兼容。
- `tools/package.py`：新增必填 `--seed-archive`，先 `validate_release_inputs()` 再写源码包/stage；失配 exit 非零且不创建任何文件。
- `tools/package_seeds.py`：抽出 `build_seed_archive(root, archive)` 供打包与测试共用；白名单统一用 `seed_library_files()`。
- 测试：新增 `tests/unit/test_release_integrity.py`；扩充 `tests/unit/test_seed_distribution.py`（目录安装兼容、ZIP 内原生 PRT 字节/路径保护）与 `tests/unit/test_seed_manifest_version.py`（受信记录、README 版本段、`--seed-archive` 必填）。
