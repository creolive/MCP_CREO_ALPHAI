# DEV-078：0.19.0 后曲面与钣金替代路线离线开发

日期：2026-11-08。类型：功能预研 / 离线实现。优先级：P2。状态：离线实现与验收完成；实机待验收，条目保持开放。目标版本：未排期。

分支：`codex/DEV-078-modeling-offline`，基点：已发布 `v0.19.0` / `86020e7`。关联 FEAT-039、FEAT-014、BUG-046、DEV-074。用户已指定实施前次讨论的替代路线，并限定先做离线开发。

## 目标与范围

1. 将被否决的单方向闭合 Boundary Blend 改为四边双方向候选；只接受四条有序周界曲线，暂不承诺任意 N 边或 G1。
2. 实现独立三面引用角部释放及 quilt 成形候选；保持真实钣金身份与板厚的要求，不用实体 union 充当成形。
3. 实现多段线/圆弧 flange 截面候选，为边缘 hem/joggle 提供底层能力；板中部 jog 不冒充同一路线。
4. 提供标准 Offset 成功参照件取树/UDF 放置准备和格栅 cut 对照夹具。没有真实成功样件时不猜造标准 Offset 树，也不生成假的 UDF/PRT。
5. 默认离线的输入、门禁、输出检查与取证准备；原生编译只验证匹配 SDK 的编译，不连接 Toolkit。

## 设计与验收

- 新候选 `sheetmetal_corner_relief`、`sheetmetal_quilt_form`、`sheetmetal_flange_profile` 进入统一 schema/native dispatch，但全部登记为 unavailable；`surface_boundary_fill` 继续 unavailable。公开工具仍为 107，不增加实验开关或自动重试。
- 原生参数使用既有 mm→模型单位转换链；未知单位拒绝，不从请求回填实际几何或成功状态。
- 旧 `sheetmetal_flange` 默认树及已有保护兼容；新截面操作独立命名，用户不能通过旧工具额外字段绕过门禁。
- 标准 Offset：先取得界面成功件及树；备选 UDF，验证源 quilt 保留、新 quilt、曲面法向距离与无实体副作用。
- corner relief：需真实 rip、flat+两 bend cylinder，不能把声明输入当成已验证 rip；实际状态与再生交 Creo 核验。
- 原生建模成功、板厚/展开、保存重载、失败回滚、Creo 9/10、非 mm、WorkBuddy 全属后续实机范围，本轮不宣称通过。
