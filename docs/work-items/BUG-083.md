# BUG-083：revolve.axis 非法结构透出裸 nlohmann JSON 异常

日期：2026-10-25 登记（外部报告 2026-10-23）。类型：缺陷（输入校验与错误呈现）。优先级：P2。状态：待开发。目标版本：0.5.3（目标，未发布）。

来源：[0.5.0/0.5.1 Creo 9 反馈计划](../development/0.5.0-0.5.1-FEEDBACK-PLAN-2026-10-23.md)阶段一/阶段三；外部第九轮报告 §四（[归档原件](../validation/feedback-0.5.0-0.5.1-2026-10-23/manifest.json)）。

## 问题或目标

已证实现象（外部 Windows 10 / Creo 9.0.0.0 / 服务 0.5.1）：首次构建回转传 `"axis": {"entity": "ax"}`，作业失败，message 为 nlohmann::json 原始异常文本 `[json.exception.out_of_range.403] key 'kind' not found`：

1. 裸 C++ 异常透出为作业 message，不含任何可操作信息（用户无从得知 axis 引用需要 kind 字段，或省略 axis 即用截面中心线）；
2. 正确用法（省略 axis，让 Creo 使用草图构造中心线作回转轴）在 revolve 的 schema/工具描述未说明，REFERENCE_SYNTAX.md 轴阵列节也未覆盖 `revolve.axis`；
3. 回滚干净（revision/体积未变，外部观察）。

目标：非法 axis 结构在工具/计划入口被预检拒绝并给出字段路径与可操作示例；原生侧保留边界防御；正确用法在工具注册描述与 REFERENCE_SYNTAX.md 说明。

## 范围

包含：

- Python 计划校验（业务逻辑进 `src/creo_mechdog/` 包内，`server.py` 仅保留注册和描述职责）与原生边界防御：拒绝缺 `kind`、错误类型、不适用引用与缺失字段；保留已有合法引用，给出字段路径及示例。`{"entity":"ax"}` 不能静默猜成外部轴。
- 显式外部轴示例使用已支持的 `{"kind":"datum_axis_feature","label":"axis_label"}`，并在同一示例中创建该轴；省略 axis 的例子必须包含有效截面构造中心线。
- 核对 axis 省略、null、空对象的既有语义并统一工具/execute_plan 行为：当前 schema 接受 None，而 native 按 `contains(axis)` 选外部引用，需覆盖此边界并明确兼容处理。

不包含：不新增轴引用种类；不改变合法 datum_axis_feature 引用与省略 axis 的既有建模行为。
