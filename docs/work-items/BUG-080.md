# BUG-080：装配变换单位契约（FEAT-045 变换数值口径）

类型：缺陷

优先级：P1

状态：开发中（实现待独立审查；实机混合单位验收按全局约束保留）

目标版本：下一未发布 PATCH（0.5.0 反馈第一批）

来源与关联：[0.5.0 验收报告 §4.1](../validation/feedback-0.5.0-2026-10-22/2026-10-22_CREO10_v0.5.0_FEAT045交付与死锁根治但变换单位存疑.md) 与[装配编辑流程改进建议 P2-2](../validation/feedback-0.5.0-2026-10-22/2026-10-22_CREO10_v0.5.0_装配编辑流程改进建议.md)；关联 [FEAT-045](FEAT-045.md)、[DEV-046](DEV-046.md)。原计划编号 BUG-079 已被就地改弧半径条目占用，本条使用 BUG-080（全 docs 唯一性已复核）。

## 问题或目标

外部 Creo 10 / v0.5.0 实测（asm_mx.asm.16，8 组件）：`creo_inspect_session_assembly` 返回的变换数值全部呈 `x/25.4` 精确形态（16 位精度可复现，如 0.30708661417322836×25.4=7.8 mm），指纹通常说明源数据为英寸存储；而 `transform_convention` 声明 `units follow the assembly (mm)`。同装配组件 mx_plate.prt.2 经 adopt 实测 `millimeter_units: true`、611 mm³——零件是毫米，装配可能为英寸建模（CAD 允许装配与组件单位不同）。若把 0.307… 当作 0.307 mm 喂给 `creo_assemble_component`（translation 明确按 mm），会产生 25.4 倍定位误差，直接破坏路线 A 重建管线精度。inspect 结果当前无 `assembly_units` 字段。单位疑点为反馈方基于数值指纹的推断、标注待作者确认，实施时以真实单位查询为准。

## 范围

包含（按 0.5.0 反馈计划第一批设计）：

- 查询组件、父装配及根装配的真实单位；`creo_inspect_session_assembly` 结果显式输出装配自身单位（如 `assembly_units: "mm" | "inch"`），并在 `transform_convention` 中写明口径（若为英寸数值即英寸，或统一换算 mm 输出）。
- 现有变换字段统一表达毫米坐标映射，新增原始矩阵及单位信息（保留原始值）。
- 混合单位必须验证完整坐标映射，不能预设只把平移乘以 25.4。
- 单位或父级变换无法确认时，规范化结果标为未知，并传播不完整状态；同时核对缺件、父变换失败及子装配遍历失败的完整性标志。

不包含：`creo_assemble_component` 的 translation 单位契约随本条文档一并明确，但不重建重建管线验收；矩阵直入参归 FEAT-012/BUG-045。

## 实现与证据

2026-10-23 登记。数值指纹与毫米旁证见[归档来源 §4.1](../validation/feedback-0.5.0-2026-10-22/2026-10-22_CREO10_v0.5.0_FEAT045交付与死锁根治但变换单位存疑.md)。

### 2026-10-23 实现（工作树 BASE d77d7f4）

- 新增 `native/assembly_units.h`：真实长度单位查询（复用 `inspection_units.h` 主单位系查询）+ `ProUnitInit(mdl, L"mm")` 与 `ProUnitConversionCalculate` 换算毫米比例；比例必须有限正数且 offset 为 0，否则保守 unknown，保留 unit/mm_unit/conversion 三个真实查询码，不与单位查询失败混报。
- `creo_inspect_session_assembly` 的 `transform_to_parent`/`transform_to_root` 改为"输入与输出坐标均以毫米表达"的完整坐标映射（行向量 p'=p*M；原始矩阵 source=组件长度单位、target=父/根长度单位）；新增 `transform_to_parent_raw`/`transform_to_root_raw`、每节点 `units.component`/`units.parent`（名称+查询码+毫米比例）与装配级 `assembly.length_unit`。
- 未知单位或未知变换时规范化矩阵为 null 并给出 `transform_unknown_reason`，原始矩阵保留，绝不伪装毫米；父变换失败沿子树传播 root unknown（不再用祖父矩阵冒充），可确认的 local 变换仍输出。
- 完整性：缺件节点置 `subtree_not_visited` 并使报告 incomplete；子装配遍历失败码写入实际返回节点（修复 push_back 后仅改局部副本导致丢失的问题）；深度硬限 32 报告 `depth_limited`；根遍历失败不再整体抛错，报告 incomplete + `root_visit_code`；`complete = !truncated && !incomplete && !depth_limited`。
- 契约声明同步：`capabilities.py` scope、`server.py` docstring、`session_assembly.py` `transform_convention`（分页快照透传 `depth_limited`）；约束 offset 明确保留父装配长度单位语义。
- 新离线原生夹具 `tests/native/test_assembly_units.cpp`（毫米/英寸/厘米、混合源/父、三基向量、非原点物理点、旋转组合验证非仅平移缩放、链式组合、非法比例/offset 拒绝）+ 运行器 `tools/test_assembly_units.py`。

### 2026-10-23 开发验证修正（fix4 收口，待独立审查）
