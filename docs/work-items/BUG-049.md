## 现象与待验证根因

外部 Creo 10 / 0.3.2：63 个梯形在一张草图中创建成功，随后切除报 `ProFeatureWithoptionsCreate=-1`、rollback_succeeded=true。报告二维计算得到相邻站位重叠 15 对、面积合计 183.9 mm²，奇偶分组为 32/31 轮廓后各组无重叠且切除成功；6 个分离轮廓对照也成功。

重叠对、面积和根因均为外部结论，本次没有其坐标包或原生日志可独立重算；不能从 -1 直接证明必然由重叠导致，也不能把所有嵌套或相切轮廓判成非法。

## 范围与复现

先核对现有 profile_checks 与原生剖面诊断的覆盖，构造两矩形交叠、相离、边/点接触、合法嵌套孔、单环自交和退化轮廓，控制基体、平面、材料相交与深度不变，分别验证草图及引用它的切除。再在输入规范化后加入履带 63 站和分组对照。

诊断输出失败操作/草图、可确认的环/实体标识、相交或退化类别、可可靠计算的量及修复指引；无法定位时明示。仅依据解析能力对已确认不合法输入提前拒绝，不能放宽检查误改几何。自动二维并集、自动吸附/分组属于需另行选型的能力，不在本项默认承诺；奇偶拆分也不能作为任意闭环的通用保证。

## 验收标准

| 用例 | 可判断的预期结果 |
| --- | --- |
| 相离多环、合法嵌套孔 | 支持输入形成正确原生切除，体积由独立解析值核对，保存重载 true，原能力不被过度预检拒绝 |
| 相交/自交/零面积 | 按实际支持边界成功或准确拒绝；失败信息能定位受影响轮廓和阶段，不只剩裸 -1，不悄悄丢环或改变坐标 |
| 相切与数值边界 | 点接触、共边、窄缝、近容差分开测试，公布适用容差/未知边界，不以任意统一阈值替代原生有效性判断 |
| 分组/尺寸编辑对照 | 几何有效的独立特征允许相互去料重叠；不能把特征之间重叠等同同剖面非法。失败回滚保持文件/revision，后续合法编辑成功 |
