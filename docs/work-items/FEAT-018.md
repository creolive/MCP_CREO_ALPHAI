## 2026-10-16 G0 复现输入（0.3.3）

[BUG-001 现版本复现](../validation/BUG-001-repro-2026-10-16.md)确认阻断（判定 a），以下实测事实作为选型输入，取代报告中未经核实的对应推测：

1. **门禁死循环根因**：载入阶段 `verify_saved` 检出会话偏离在任何操作前抛出，而 `mutated` 标志仅由本作业写操作置位，`rollback_to_saved_checkpoint`（要求 `connected && mutated && checkpoint`）不触发，脏会话保留。修复须覆盖"载入即偏离"分支的受控处置（准确报告偏离证据，或授权后擦除会话副本并从磁盘基线重载）。
2. **三类处置对象已被实测区分**：已保存未交付（磁盘 prt.2 存在、未登记、revision 不动）；会话偏离（门禁循环）；无 checkpoint 新模型（人工解锁后写操作静默采纳 26/62 特征的半成品为新基线——该采纳行为本身须收紧为拒绝或显式确认）。
3. **恢复接口缺口**：82 个公开工具无任何恢复/清锁/接受/协调入口；`get_job` 已附 `recovery` 证据（`automatic_replay_allowed=false`、`native_result_present` 等），可直接作为只读证据查询的基础。
4. **重启语义**：报告的"重启后可续建"已实测成立，但仅限真重启（结束 xtop 全进程）；杀 parametric 启动器桩的伪重启不换会话。恢复指导与检测须绑定真实会话进程身份；隔离复现采用的全进程终止不得直接作为产品自动恢复策略。
5. **恢复次序**：unknown 后通道健康失效层先于模型层拒绝一切提交，受控恢复流程须先走 `creo_startup_status(retry=true)` 复核，再做模型协调。

## 目标与范围

让操作者能通过正式流程核对异常作业，并在证据充分时恢复到确认的保存基线，或按明确授权接受已验证的会话成果；不能以人工编辑 model.json 作为产品恢复流程。先设计状态机、所有权、授权与结果契约，再选择接口。初次报告中的名称曾为候选；本开发分支现实现 `creo_reconcile_model`，四动作及限制见[使用说明](../MODEL_RECOVERY.md)。公开0.3.3没有该入口。

保留已有写操作的检查点、失败回滚及 unknown_outcome 保护。分别定义未尝试/成功/失败/无法确认回滚、当前模型可用性、新建失败模型的归档/重试边界、已执行但随后回滚的操作历史。删除特征是正常编辑能力，不能替代未知状态协调；不因报告未列出某计划 op 就认定独立工具不存在。

## 设计和执行顺序

1. 消费 BUG-001 的最小复现与证据矩阵，核对服务、模型、worker 和检查点身份；原生通道仍只有一个。
2. 定义只读证据查询与写恢复的边界、expected_revision/处置令牌或等价的过期证据保护、授权条件、审计记录和幂等性。
3. 优先实现可证明的回到保存基线分支；接受 live 分支须另有几何/原生特征健康、保存重载、资源引用和模型归属的完整核验，无法证明时准确拒绝，不视为必然可恢复。
4. 定义恢复中的失败和再次中断如何保持保护，避免“先清锁再验证”的窗口。新建失败件的清理只处理本项目所有且经核对的产物，不能删除用户模型或原始证据。

## 验收标准

| 场景 | 可判断的预期结果 |
| --- | --- |
| 基线恢复 | 主动选择丢弃会话变更前授权条件明确；恢复后文件、特征/尺寸/参数/体积与确认检查点一致，原始异常作业及审计记录保留 |
| 已保存但未交付 | 不按 prt 序号直接提交 revision；明确保存、重载与登记状态，选定成果经核验后只提交一次 |
| live 接受候选 | 不兼容、失联、引用不完整或模型不健康时拒绝；支持分支只有保存重载及身份核验通过后才发布可用终态 |
| 竞争/过期/中断 | 活动 worker、通道繁忙、expected_revision 或证据已变化时准确拒绝；重复调用和恢复再次失败不误清未知保护 |
| 正常失败回滚 | 正常几何失败的旧回滚路径不退化；成功结果不会因 rollback_succeeded=false 被误写成模型损坏 |
| 后续建模 | 协调成功后可安全继续编辑，revision/检查点一致，saved_file_reloaded_and_verified=true；未知原作业不自动重交 |

开发：Windows x64 / Creo 12.4 / 匹配 SDK，统一检查、适用原生恢复与保存重载回归。WorkBuddy 仅调用实现后正式公开接口，不编辑配置/状态、不触发内部故障注入，未能由接口观察的机制记未验证。其他 Creo 环境按反馈补录。
