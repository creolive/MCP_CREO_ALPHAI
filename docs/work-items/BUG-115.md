（Creo 12.4.0.0 / 匹配 SDK，报告 `build/surface_save_recovery/20261106-120635-343700/report.json`）。

## 现象

`single_plan` 路线、独立平面工具组（`surface_fill` → `surface_trim`（datum plane 工装）→ `thicken`
（`quilt_feature` 引用同计划刚创建的 `recovery_trim`）一次提交时，3 个独立模型全部在 thicken 失败：

```
Toolkit call ProFeatureGeomitemVisit(&f, PRO_QUILT, collect_geom_ids, nullptr, &ids)
failed with code -4 during execute_thicken
```

- job 示例：`8439c805e272437ab22986639c304448`（第 1 个模型）。
- 失败回执 `rollback_succeeded=false`、`save_failure=null`、`rollback_difference=null`；
  三个模型的 part_file/part_sha256/revision 基线全部不变，判定 `model_status=failed`，unknown 保护未释放。
- 对照：`incremental` 路线把 trim 与 thicken 拆到不同提交后 3/3 成功（`model_status=ready`，
  `rollback_succeeded=true`）；`single_plan` + 投影依赖组（3 例）也全部 ready。
- 同批 `single_plan` + 独立平面组是唯一失败组，故与保存失败/回滚差异无关，指向“同一再生批次内
  trim 生成的 quilt 尚不可被 thicken 访问”。

## 推测根因（待验证，不得当成结论）

trim 与 thicken 在同一计划（同一原生提交）内连续创建时，thicken 通过 `quilt_feature` 标签解析到
trim 的 quilt，但该特征尚未经历一次再生，`ProFeatureGeomitemVisit(PRO_QUILT)` 因此返回 -4。
需在原生侧确认是批次再生时序还是标签解析取到了错误特征；未验证前不修改调用顺序。

## 下一步

- 原生只读探针：同计划 fill→trim→thicken 在 trim 后强制 `ProSolidRegenerate` 再 thicken，对比 -4 是否消失。
- 若确认是再生时序，评估“同一计划引用刚创建的 quilt 特征”的统一准入：要么在原生分阶段再生，
  要么在 Python 校验阶段拒绝并给可执行替代（拆分提交 / 显式引用已存在 quilt），不能只把 -4 转述给用户。
- 不把本项与 BUG-113（Backup/回滚失败）合并：本项没有保存失败，基线不变，失败发生在几何访问。

## 2026-11-07 离线实现（按上节第二选项）

在 `src/creo_mechdog/schema.py::validate_operations` 增加同计划准入：当 `thicken` 以
`quilt_feature` 引用同计划中较早的 `surface_trim`，且该 trim 的 `target` 也是同计划中较早创建的
quilt 特征（即整条 fill → trim → thicken 都是本计划新建）时，在创建 job 前拒绝并给出可执行替代：
先提交 fill/trim，再在第二个计划中引用已存在的 quilt 特征，或使用 `creo_inspect_model` 读回的
显式 `{kind:"quilt", id:N}`。

- 范围有意收窄：`single_plan` + 投影依赖组已知 3/3 成功，其 trim 的 target 来自更早提交，
  不在拒绝范围；`fill`→`thicken` 与显式 quilt id 也不受影响。
- 回归：`tests/unit/test_surface_trim_schema.py` 三条（拒绝整链新、放行旧 target、放行其它 producer）。
- 驱动：`tools/test_surface_save_recovery.py --live` 把该组的提交前拒绝记录为
  `model_status=refused_expected` 并给出拆分动作，不再计为原生失败。
- 本变更未确认原生根因；若后续原生分阶段再生修复，可移除该准入。

## 2026-11-07 实机复验（本机 Creo 12.4.0.0 / 匹配 SDK，用户授权会话）
