# BUG-041：非偏移装配约束静默丢弃 offset

## 当前摘要（2026-11-07，DEV-073 复核）

分类：**待复现/待核实**。当前结论：原生当前对所有装配约束调用 OffsetSet；普通 mate/align 非零值是否被忽略缺回读证据。

剩余范围：先定普通约束非零 offset 契约，再加准入拒绝或显式转换，验证面距及保存值。推进依赖：原始约束输入/回读，或构造最小对照的 Creo 会话。

证据：[本卡原始记录与证据](#dev073-history)。本次仅核对既有记录/源码，未做新的实机验收。
