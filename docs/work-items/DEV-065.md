## 关键决策

1. **不做 `verify_model` 进程内强杀**：Toolkit 调用不可中断，提前杀 worker 会把"慢但成功"的保存变成新的 `unknown_outcome`；只做子阶段归因 + 停滞判定，总预算与 `unknown_outcome` 语义不动。
2. **刚性平移改判据、不放宽默认阈值**：形状仍按 1e-5 严格拒绝；只有可证刚体平移且平移量 ≤ `1e-2 mm` 才放行并标 `accepted_rigid=true`。取代 R12"默认值不调整 + 拒绝"的二分结论（见 [MAPPING §五](../validation/feedback-0.11.5-2026-11-03/MAPPING.md)）。
3. **装配只加元数据动作**：四个触碰组件所有权的动作继续对装配不可用；`ack_failure` 不改 revision、不改文件、不改组件。
4. **旋转范围是行为收紧**：225° 以前能过校验但内核必败，改为前置拒绝并给等价值；需在版本说明中写明。
5. **`verify_model` 卡死不并入 BUG-088/085**：BUG-088 是预览文件缺失、BUG-085 是断连调查，只作对照材料。
