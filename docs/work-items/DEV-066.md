## 登记内容（报告方实测，本仓未复算）

1. **git 硬依赖**：`grep -rl '\["git"' tools/` 命中 **37 个工具**，其中 **32 处 `check=True`**，无 `shutil.which("git")` 或 `FileNotFoundError` 兜底。无 git 时 `python tools\test_unit.py` 得 `2196 tests / errors=38`，traceback 为 `subprocess.run(["git", ...], check=True)` 的 `FileNotFoundError: [WinError 2]`；把 PortableGit 加入 PATH 后 2196/2196 通过。
2. **受影响人群**：用 GitHub Release 源码 ZIP 安装（ZIP 无 `.git`、机器通常无 git）、精简/离线环境；**MCP 服务本体不依赖 git**。
3. **负例输出易误判**：全量测试 stdout 打印 `ERROR: Seed archive SHA256 ... differs from docs/seed_package.json ...` 等红字，实为负例夹具（`test_tampered_archive_bytes_are_rejected`、`test_trusted_record_digest_mismatch_is_rejected`）的预期输出，最终 `success=true`；每次摘要值不同，外部用户易误判为种子包不可复现。
4. **运行时数据被跟踪**：`session_activity.json` 仍由服务运行时追加且被 git 跟踪，升级会覆盖用户会话记录（建议 gitignore 或文档说明）。
5. **低优先级建议**：`lock_files.py` 的 `open_lock_file` 初始 `OPEN_EXISTING` 瞬时 WinError 5 仍未兜底（10-21 反馈）。
