## 现象

YZ 平面 offset=92.5，单线 `(-116,0.5)→(116,0.5)`，`sheetmetal_wall(depth=185, thickness=1, direction="negative")`：

- 结果 V=42920 = 185×232×1，COG `[0,0,0.5]`，与冻结契约一致（正面）。
- `inspect_model(edges)`：边 104/105/106/107 起点终点均 Z=0。
- 挂四道 `sheetmetal_flange`(h=80, R2.54, Y=0.5)：`f_px`(104)、`f_nx`(105) 成功；`f_ny`(106) 失败：
  `ProSmtedgeContourGet returned PRO_TK_BAD_CONTEXT (-8), so this edge is not on a sheetmetal wall face (green/white contour).`
- `f_py` 未执行，整批回滚只剩底板；S3 四壁仍建不出来。

报告方判读：体积正确的底板，其 Z=0 两条长边未被登记为壁面轮廓边界，而 X=±92.5 两条短边被登记；疑与“第一壁折弯侧”判定有关。这与 0.3.x 起“第 3 道折边失败”方向一致。

## 当前实现状态（0.11.1 只读核对）

- 候选边可从事前查询：`native/generic.cpp:419-431` 每边一次 `ProSmtedgeContourGet`（256 边预算），`src/creo_mechdog/sheetmetal.py:177-260` 投影为 `wall_contour_status=eligible|ineligible|unknown` + `wall_contour_query_code`，按 revision 标注；`eligible` 明确不解除 `adjacent_bend_ends` 拒绝。
- 壁面回显：`wall_contract.wall_face_ids` 与 `parameter_hint`（仅 `thickness >= depth` 触发）见 `native/advanced.cpp:624-683`；注释已记录“2026-10-31 反馈的 185×232×1 板，green/white 壁面是 185×1 rim 条”。
- 失败文案已重写为帧契约 + `wall_face_ids` + YZ 配方指引（`advanced.cpp:1396-1412`），**但该指引推荐的正是 R2 已失败的配方**，属新的口径矛盾。
