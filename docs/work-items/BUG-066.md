# BUG-066：preview.jpg 渲染与实际几何不符

日期：2026-10-18。类型：缺陷。优先级：P2。状态：待复现。目标版本：未排期。

来源：外部 0.3.5 能力边界反馈 P7（Creo 10.0.0.0 / release 42），见[原件](../validation/FEEDBACK-0.3.5-CAPABILITY-2026-10-18.md)。

## 报告现象（外部实机）

Part1 星形架在斜槽种子切除后：同一 job 的 `inspection.volume_mm3=16028.4006`（切除量 77.87 与解析一致），但 `preview.jpg` 把零件渲染为 **7~8 根互不相连的长条、圆盘完全消失**。后续体积累加（+347.474、+83.621）与解析值精确吻合，证明**体积可信、预览不可信**。疑似渲染了未缝合曲面或错误的 display set / tessellation 状态。

影响：目视验收失效，只能靠体积/面数间接判断，排障成本显著增加。

## 待核对

- 本机复现：对已知完好的盘类零件连续提交若干特征，逐 job 检查 preview 与体积/面数的一致性，定位何时开始失真（特征类型相关性：切除/阵列/基准面之后？）。
- 核对预览导出的视图状态、display list 与再生时机（是否在中间再生状态截取）。
- 修复前不给预览加任何"验收依据"地位；文档注明预览仅供非正式参考。
