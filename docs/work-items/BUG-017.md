# BUG-017：合法开放剖面rib再生失败

类型：缺陷；优先级：P1（本轮调整）；状态：验收中；目标版本：未排期。

来源：台账Creo12 L形件YZ开放线及2026-10-14 Creo10 XZ开放轮廓两种flip失败；不推断所有rib均不可用。

范围：草图/实体相交、材料侧、厚度方向和原生创建/重定义；合法正例、两种flip方向对照、非法/不相交剖面回滚。必须验证原生筋特征、几何、保存重载和revision，不用薄拉伸替代。环境和命令见[联合任务](P1-MODELING-REPAIR.md)。

## 本轮交付

材料侧在剖面定义后设置；两flip配合相应端点方向和三厚度侧通过；闭合/不相交拒绝及实际回滚通过。

开发阶段记录：[独立证据](../validation/BUG-017.md)、[联合证据](../validation/P1-MODELING-REPAIR.md)。当时尚待 WorkBuddy 最终验收，后续进展见下文；原环境输入未齐的事实保留，不作为独立复测要求。
