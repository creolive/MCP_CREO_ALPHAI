# DEV-045：Release body 固化两包 SHA256 检查

类型：工程整理

优先级：P2

状态：已完成（外部确认关闭，2026-10-23 按 0.5.0 外部报告三 §4 关闭并移入完成档案）

目标版本：未排期

来源与关联：[0.4.4/Creo 10 反馈](../validation/feedback-0.4.4-2026-10-21/report-dev027-030.md) §4.1 与 §5.1（"0.4.1/0.4.2 直接写在 Release body（我建议过并获采纳），0.4.3 也在 body，0.4.4 的 body 没写……建议固定为 Release body 必含两包 SHA256"）。

## 问题或目标

附件校验和的呈现方式在版本间漂移：0.4.1～0.4.3 的 Release body 直接列出源码包/种子包文件名及完整 SHA256，0.4.4 漏写（只能去 main 分支 `docs/validation/RELEASE-0.4.4.md` 取），下游升级者被迫多走一步且无稳定预期。

## 范围

本次包含：

- `docs/development/RELEASING.md` 发布清单固化：Release body 必须直接列出源码包、种子包的文件名及完整 SHA256，并随发布核对流程核对远端附件与 body 一致。
- 发布历史与已发布附件保持原样，不回填旧 Release。

不包含：自动化发布脚本改造（现有手动流程上增加检查项即可）；旧 Release 补写。

## 验收标准

| 环境 / 用例 | 命令或操作 | 可判断的预期结果 |
| --- | --- | --- |
| 文档 | RELEASING.md 评审 | 清单明确包含"Release body 两包文件名+SHA256"及远端核对步骤，与既有版本发布规则无冲突 |
| 下次发布 | 按清单执行 | Release body 含两包 SHA256 且与远端附件哈希一致 |

## 实现与证据

2026-10-21 实施（分支 `codex/bug077-registry-split`）：`docs/development/RELEASING.md` 发布门槛新增第 7 项——Release body 必须直接列出源码包与种子包文件名及完整 SHA256，发布后核对远端附件哈希与 body 记载一致再报告交付完成，并说明已发布 Release 与附件保持原样不回填；发布回归记录模板同步标注（文件名与完整哈希写入 body、远端逐项核对）。

下次发布（随 BUG-077/FEAT-047 的交付）实际执行时按本条核对；本条自身为文档改动，不单独触发发布。

2026-10-21：本批版本由用户指定 0.4.7 PATCH；此处仅同步开发分支目标，实际 Release body/双附件核对须在后续交付流程执行，不能提前标通过。

### 2026-10-22 首次发布执行核对通过 + 命名固化结论

[0.4.7 发布核对](../validation/RELEASE-0.4.7.md)：Release body 列出 `MCP_CREO_MechDog-0.4.7-source.zip`（SHA256 `d8550540…`）与 `MCP_CREO_MechDog-0.4.7-seed-library.zip`（SHA256 `5f91b8d2…`，与 `seeds.py` expected_digest 一致），远端附件下载复核哈希与 body 记载完全一致——**验收标准"下次发布按清单执行"首次实际执行通过**。

[0.4.6 外部报告一](../validation/feedback-0.4.6-2026-10-21/manifest.json) §4.1 第四次提出附件命名问题（0.4.6 实际为 `MCP_CREO_MechDog-seeds-0.4.6.zip` 版本号中置，累计第四种变体）。核对结论：`tools/package.py` 产物名 `MCP_CREO_MechDog-{version}-source.zip`、`tools/package_seeds.py` 产物名 `MCP_CREO_MechDog-{version}-seed-library.zip` 已固定，0.4.7 起按此定名发布；历史附件与旧 Release 保持原样不回填。外部环境对 0.4.7+ 命名的确认仍开放，随下次外部反馈闭环。

### 2026-10-23 外部确认关闭

[0.5.0 外部报告三 §4](../validation/feedback-0.5.0-2026-10-22/manifest.json)（归档件，来源字节数/SHA256 见 manifest）确认：两包命名自 0.4.7 起按 `MCP_CREO_MechDog-{version}-source.zip`/`-seed-library.zip` 定名执行，0.5.0 两包回归定名并附 `.sha256`，Release body 含双包完整 SHA256 且远端下载复核一致（源码包 `dd8b49bb…`/种子包 `fb84a37d…`）。RELEASING 第 7 项已于 0.4.7（2026-10-22 首次）与 0.5.1 两次实际执行核对通过。验收标准中"下次发布按清单执行"与"外部环境命名确认"两项均按已有外部证据关闭；本条仅依据既有外部报告结论登记，本轮未重新联网核验。完成摘要见[完成档案](../BACKLOG_COMPLETED.md)，以上历史原文与日期保留。
