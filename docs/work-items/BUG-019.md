# BUG-019：圆角、倒角的参数说明与返回一致性

日期：2026-10-18 补建独立卡，沿用原 ID。类型：接口说明与兼容改进。优先级：P2。状态：验收中（DEV-042 已实现，黑盒复核待服务重启）。目标版本：未排期。

## 已确认的范围

`server.py` 的独立 `creo_round` 使用 `radius`，`creo_chamfer` 使用 `distance`，两者明确转换成计划操作的 `size`；`RoundOp.size` 与该路径一致。这个映射已经可以从代码确认。外部 0.3.1、0.3.4 和 0.3.5 的参数名差异反馈保留，见[0.3.4 反馈](../validation/FEEDBACK-0.3.4-2026-10-17.md)及[最新 Creo 9 反馈](../validation/FEEDBACK-0.3.5-CREO9-2026-10-18.md)。

按 [DEV-039](DEV-039.md) 归入已确认待开发的接口说明工作，关联 FEAT-008。下一步明确每个入口的字段、参数映射和返回示例，评估是否需要兼容别名或补充返回字段。本次不直接统一改名，也不把名称不同认定为原生建模失败。

## 完成要求

独立工具与 execute_plan 都有可直接使用的例子；旧请求保持兼容，冲突输入明确拒绝。返回值应能与调用者输入及计划中的 size 对照。仍须核对圆角半径、倒角距离的实际原生尺寸和保存重载，不能靠文档改写宣称尺寸已验收。

Windows/Python 做输入和协议回归；涉及原生行为时按本机 Creo 12.4/匹配 SDK 规则验证，WorkBuddy 仅通过 MCP 验收。原外部失败、未测范围及源码身份分别记录。
