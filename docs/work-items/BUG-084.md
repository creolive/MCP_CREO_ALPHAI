# BUG-084：平面引用的显式 id 被忽略并回退默认 Z 平面

日期：2026-10-26（Asia/Shanghai）。类型：缺陷。优先级：P1。状态：待复现（静态实现缺口已确认，原生现象与影响待验证）。目标版本：0.7.0。

来源：[0.5.2 反馈计划](../development/0.5.2-FEEDBACK-PLAN-2026-10-26.md)，第三份报告 §3、§5；关联 [BUG-064](BUG-064.md)、[BUG-065](BUG-065.md)、[BUG-063](BUG-063.md)、[DEV-047](DEV-047.md)。执行归 [派发表 T03](../development/0.5.2-FEEDBACK-TASKS-2026-10-26.md#t03-common-plane-frame)。

## 现象与已知事实

外部 Creo 10 / v0.5.2 报告：datum_plane 引用中的 id 指定 Right/倾斜平面后，纯 Z 向 u_axis 报 Zero direction vector；倾斜面切除实际表现类似沿 Z；历史两平面求交轴与偏心阵列存在错误几何报告。

main `2af3853` 静态核对：`native/generic.cpp` 的 resolve 在 kind=plane/datum_plane 分支只读取 normal 或 axis（默认 z）、offset，并遍历几何匹配；不读取 id。Python 的同类引用校验亦不校验该分支的 id。因而看似显式指定 ID 的输入可被接受后按默认 Z 平面筛选。此缺口可解释多项现象，但不能据此断言拉伸或阵列不存在独立缺陷；未在当前会话做复现。

## 修复范围与契约

- datum_plane.id 表示当前模型巡检 datum_planes 中的基准平面几何 ID；plane.id 表示平面几何 ID，需验证确实平面。特征标签使用既有 datum_feature，几何与特征 ID 不互换。
- ID 与 axis/normal/offset 筛选互斥；显式 ID 类型错误、不存在、对象类型错误或组合歧义准确拒绝，不能回退默认平面。无 ID 时保留既有几何筛选语义。
- Python 入口与原生边界共同校验，所有调用者共用同一解析契约；不只修补 extrude 或 axis_pattern。
- 草图结果公开实际支撑面及局部帧；有效纯 Z 向面内方向可用，零向量和与法向平行的方向有准确错误。
