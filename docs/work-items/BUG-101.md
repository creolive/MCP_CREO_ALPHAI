# BUG-101：近容差端点间隙导致拉伸 `-1`，且无准入判据与失败归因

日期：2026-11-02。类型：缺陷。优先级：P1。状态：已修复并随 0.11.2 发布（风险标记 + 拉伸失败簇内间隙归因）；本机 Creo 12.4 未能命中失败样本，报告方 Creo 10 的 `-1` 未复现。目标版本：0.11.2。关联 [BUG-049](BUG-049.md)（诊断子项已交付，本卡为能力/归因缺口）、[FEAT-008](FEAT-008.md)（草图结果投影）、[DEV-060](DEV-060.md)。

## 来源

- 原件：[0.10.0 第十轮反馈 F02 §一 P1 / §三](../validation/feedback-0.10.0-2026-10-31/originals/20261031_CREO_v0.10.0_端点焊接诊断已补齐但仍不可焊_draft方向取反静默失败.md)，归档与逐章映射见 [MAPPING](../validation/feedback-0.10.0-2026-10-31/MAPPING.md)。
- 环境：外部 Creo Parametric 10.0.0.0、MCP 0.10.0、94 工具。

## 现象（已由报告方实测，本仓库尚未复现）

10 环 40 弧草图 `gear10.json`：`max_endpoint_gap_mm = 8.215e-7`、`near_tolerance_pairs.total = 40`、`closure_tolerance_mm = 1e-4`；`native_section` 报 10 closed / 0 open end。对该草图 `extrude add blind 10` 返回 `ProFeatureWithoptionsCreate=-1`。

同一几何吸附到 7.83e-13 后（`near_tolerance_pairs.total=0`）同一操作成功，`volume = 1849.8028532376422`。

失败信息只复述计数：

> Detected native section: 10 closed contour(s), 10 contour(s), 40 entity(ies), 0 open end(s). These counts do not identify the cause; the cause is not determined.

即：诊断字段（`max_endpoint_gap_mm`、`near_tolerance_pairs`）就在回执里，但**失败归因没有引用它**；调用方拿到“计数完美闭合 + 原因未定”。

## 当前实现状态（0.11.1 只读核对）

- `near_tolerance_pairs` / `max_endpoint_gap_mm` 仅出现在 `src/creo_mechdog/operation_results.py` 的投影（纯透传），准入层（`profile_checks.py`）与原生拉伸失败路径均无判据引用。
- 现有聚类容差为 1e-4 mm，用于“是否闭合”的放行，与 Creo 内核焊接容差不是同一量纲：0.82×该容差（8.2e-7）不可焊，7.8e-13 可焊。
- 无任何 `weldable` 类判定字段（全库 0 命中）。

## 2026-11-02 离线实现（实机未验）

- 新增 `src/creo_mechdog/weldability.py`：`WELD_TOLERANCE_MM = EXACT_TOLERANCE_MM`（1e-9 mm）。这是仓库既有、且唯一落在“7.83e-13 可用 / 8.215e-7 被拒”之间的公开常量（坐标尺寸求解 epsilon），**不是新标定值**；`note` 明确只保证 `endpoint_welding_only`，不保证特征成功。
- `operation_results._profile_summary` 在草图 `profile` 中新增 `weldability{available, weldable, max_endpoint_gap_mm, weld_tolerance_mm, tolerance_source, guarantee_scope, exceeding_pairs{total, truncated, sample≤20}, note}`；`weldable` 在不可判定时为 null（unavailable/partial/无 gap/非有限值），开轮廓直接 false。默认**只报告不拒绝**，不改 1e-4 聚类放行语义。
- `native/generic.cpp` `section_create_failure`：`open_ends==0` 但 `max_cluster_spread_mm>0` 时，失败信息改为点名“端点只在诊断聚类容差内相连、内核不保证焊接”并给出下一步动作，替换“the cause is not determined”；原句仅作最后兜底。
- 显式 `weld_tolerance_mm`：函数级支持（严格校验有限正数、拒绝布尔），`tolerance_source="request"`；**尚未**开成公开工具参数（需改 schema 与 `creo_create_sketch` 签名），列为本卡剩余。
- 证据：`tests/unit/test_endpoint_weld_gate.py` 15 项通过（阈值两侧、显式容差、非法值、开轮廓、不可用、partial、样本有界、边界相等、NaN、投影、原生归因）；`tools/test_endpoint_weld_gate.py` exit 0，报告 `build/bug101_weld_gate/20261102T164015_1976acb5/report.json`（SHA256 `C48AB7EDB04EC19058A7D76EC53D596F740671130B2B3477151EA0C544F66EBB`，41 439 B，含 commit/dirty/源码指纹）。
- **原生构建与全量回归（2026-11-02）**：`bridge.py build` exit 0（`build/creo_worker.exe`，`build/source.sha256=ffe75d9b8cfee046e4436714280ded1df28df1a45c056fe379959e98bf889b16`）；`tools/dev_check.py --work-item R10` `success=true`、单元 2 130 项 0 失败、样式无回归。
- **2026-11-02 本机 Creo 12.4 实机（未复现）**：同一 8.21534262415399e-7 mm 间隙、10×10 方框、`dimensioning=auto`、`creo_extrude` add blind 5 **成功**（`succeeded`，吸附对照体积 500.0）；`profile.weldability.weldable=false`、`exceeding_pairs.total=1`（`s0`/`s3`）、`tolerance_source=measured_constant`、`guarantee_scope=endpoint_risk_flag`。即报告方 Creo 10 的 `-1` 在本机不可复现，原生失败归因分支因此**未被触发**。
- **由此修正语义**：`weldable=false` 只表示“超出已测安全界、未被证明可焊”，**不是**“会失败”；`note`/README 已写明“risk flag, not a prediction”。1e-9 只是保守界，不是内核焊接容差。
- **未验**：`gear10` 原件仍缺；报告方 Creo 10 环境不可得，跨版本差异未定因；失败归因文案只有源码契约断言，无实机命中记录。

## 范围

包含：

- 明确“可焊性”判据：以实测可用阈值为依据给出 `weldable`（或等价三态）与 `endpoint_gap_exceeds_weld_tolerance` 判定，阈值来源必须实测标定，不用猜值。
- 拉伸失败归因：当轮廓闭合但存在超阈端点间隙时，失败信息引用 `near_tolerance_pairs` 前若干对（有界样本）与阈值，而不是继续输出“原因未定”。
- 可选收紧：显式 `weld_tolerance_mm`（沿用 FEAT-010 `geometry_tolerance_mm` 的“显式请求才强制”先例）；缺省不改变既有 1e-4 聚类放行语义。

不包含：

- 不实现端点自动焊接/吸附改写用户输入（属于几何改写，需单独设计与同意）。
- 不改变多环/嵌套轮廓的支持结论（归 BUG-049 原案）。
