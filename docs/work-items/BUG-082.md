## 问题或目标

已证实现象（外部 Windows 10 / Creo 9.0.0.0 / 服务 0.5.1，2026-10-23 18:28–19:00；在另一模型重复，排除状态污染）：

- 干净模型 `wb_acc051_axis`，XZ 面、构造中心线为回转轴，剖面为扇形：l1 (0,0)→(10,0) + arc 圆心 (0,0) / R10 / 0°→90° + l2 闭合回轴线；初始 execute_plan（sketch+revolve）成功，体积 2094.3951 mm³ = 2/3π·10³（**上半球**，不是完整球）。
- 就地编辑弧 90°→80°（同步相邻端点，剖面有效闭合）失败：`Regeneration produced a failed, suppressed or incomplete feature`；改半径 R10→R12（同步所有闭合边）失败；显式 `dimensioning="coordinates"` 同样失败。
- 三次失败回滚均干净（revision、体积、文件未变）。失败作业 native.log：草图 REV_SK `status=0`（成功）、回转特征 REV1 `status=6`（失败）——**草图编辑成功、下游回转再生失败**。
- 对照：BUG-079 离轴夹具（弧圆心偏离轴线）在同一外部会话 R5→R6→R5 全部通过，数值与 Creo 12.4 逐位一致；作者球体夹具（端点在轴上）历史上从未触发 BUG-079 失败、修复后夹具又刻意离开轴线，“剖面顶点在回转轴上”构型无任何用例覆盖。

待验证：**根因尚未确定**，不能先断言与 BUG-079 根因独立，也不能把所有贴轴剖面写成必然失败。报告未附完整 entities、中心线方向与失败输入 JSON，复现输入需补齐，不能只靠报告摘要猜测。
