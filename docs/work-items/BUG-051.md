## 现象与待验证根因

外部 Creo 10 / 0.3.2：与 coordinates 对照的线弧相切闭链改为 autodim 后 `SKETCH_SOLVE=-1`、`SECTION_ERRORS phase=solve count=0`、`AutodimensionSketch=-1`；20 直线截面的自动标注对照成功。报告认为 Intent Manager 状态和 solve/autodim 顺序是根因，尚无本机复现，不能直接据此颠倒全库调用顺序。

## 范围与实施

先复用 BUG-050 冻结后的精确几何，区分已有显式约束和未约束输入；记录创建、Intent Manager 状态、solve、autodim、regenerate 的实际调用与返回，分别测试开链、闭链、单弧、线弧相切、纯线及已完全约束剖面。只修改被证实受影响的求解路径，保持现有坐标模式和原生尺寸语义。

不默认降级到其他 dimensioning 模式，不静默删除约束、不只靠放宽误差让结果通过。若某组合不支持，准确说明范围和可操作替代，不能声称所有 autodim 失败或已修复。

## 验收标准

| 用例 | 可判断的预期结果 |
| --- | --- |
| 支持的精确相切闭链 | 自动标注、求解、再生成功，回读几何及闭合性正确，原生尺寸可编辑且保存重载 |
| 单弧/纯线/已约束输入 | 原成功路径不回归，不产生重复尺寸或额外自由变形 |
| 不支持或非法组合 | 明确失败阶段、Toolkit 返回和可取得的剖面诊断；诊断数量为零时如实说明，不凭空补根因 |
| 扫描及失败回滚 | 合法下游扫描成功，失败时不保留脏草图或推进 revision，后续正常建模可用 |
