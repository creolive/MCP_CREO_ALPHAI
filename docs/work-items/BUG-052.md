## 目标与范围

先确认现有 `type` 表达的是 Toolkit 对象类别还是曲面几何类别。统一出现 34 可能是字段语义与调用方预期不同，不能仅凭平面样本认定 SDK 返回错误。以平面、圆柱、圆锥、球/环面及自由曲面的最小原生件分别核对来源。

在兼容旧返回的前提下明确对象类型与几何类型，评估新增独立 geometry_type / is_planar 等字段和可靠的原生参数；名称、枚举和值在选型后确定，不擅自替换已有 type 含义。半径、法向/原点仅在有定义的曲面上提供，不能用 bbox 猜曲面种类，无法取得时保留未知。

## 验收标准

| 场景 | 可判断的预期结果 |
| --- | --- |
| 各原生曲面类别 | 查询与实际原生几何一致；对象类别与几何类别有明确区分，平面可作为可靠筛选条件 |
| 轴向/半径等派生值 | 对支持种类与独立建模参数一致，不适用/无法确定的字段不伪造数值 |
| compact/full/分页 | 同一曲面 ID 和语义一致，有完整性与详情入口；不扩大默认返回为全量几何 |
| 引用与旧客户端 | 不改变既有 ID 或默认引用行为；旧 type 兼容方案有明确迁移说明，后续基于真实面选择的建模与重载通过 |

开发环境 Windows x64 / Creo 12.4 / 匹配 SDK，统一检查、受影响原生查询/引用与保存重载回归；WorkBuddy 通过 MCP 构造已知几何并核对公开字段，源码/枚举调用机制不纳入黑盒结论。
