# BUG-094：基准面创建参数类型与静默丢参

日期：2026-10-31。类型：缺陷。优先级：P1。状态：开发中（P06 离线实现已交付，构建与实机待排期）。目标版本：未排期。

来源：[F3 原件](../validation/feedback-0.9.0-2026-10-31/manifest.json) 问题 1—4；[逐章映射](../validation/feedback-0.9.0-2026-10-31/MAPPING.md)。关联 FEAT-008、总计划 P05/P06。与 [BUG-031](BUG-031.md) 的镜像**已有面选择**分开；本卡针对独立 datum 创建及其 axis 引用。

## 现象与待验证根因

报告称轴 label 在 `datum_feature` 路径被报成“不是基准面”，缺 `kind` 抛出缺键异常，`kind:normal` 与说明冲突，angle 与非零 offset 同时提交时 offset 静默丢失，±54° 方向与预期相反。`datum_axis_feature` 已有解析；`normal` 过滤器只匹配已有面。当前 offset_plane 分支存在丢 offset 的静态线索，但本次未运行同一输入复现。角度符号必须先核实际有向轴，不能由名称推断。

## 范围与验收

P05 先对齐引用类型和工具说明；P06 冻结独立创建契约：缺 kind、错类型、未知 label 给可判断错误；显式 angle（含 0）与非零 offset 组合明确拒绝，不悄然建两道特征。保留单独旋转、单独偏移和 angle+offset=0。若需单次组合，另作能力设计。

Windows x64 / Python 3.12+ 专项单元回归；本机 Creo 12.4.0.0 / 匹配 SDK / MSVC 在 P01/P02 会话条件满足后，分别用独立工具和 plan、正负轴与 ±54°、零角、偏移及旋转后显式偏移核真实法向/位置、编辑与保存重载；非法输入核无残留特征、revision 不变。Creo 9/10 本机原生范围未验。P00 只登记，不宣称修复。
