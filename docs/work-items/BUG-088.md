## 2026-10-30 N11 离线阶段：空件失败在本机历史作业中可复现，判别量已确定

| 分组 | 作业数 | 写出 `preview.jpg` | 出现 `failed_step="output_file"` / `failed_code=-4` / `bytes=-1` |
| --- | ---: | ---: | ---: |
| 新建 + 零操作 | 330 | **0** | **46** |
| 新建 + 有操作 | 942 | 841 | **0** |

分离度 100%，无例外；与模型名、模板、体积、面数无关。关键区分事实：

3. **失败发生在栅格调用成功之后**：46 份 `native.log` 显示 `display`/`refit`/`refresh`/`repaint`/`raster` 全部返回 0，之后才落到 `output_file`；`window=1001`、`window_matches_model=true`、`current_window_matches=true`。
