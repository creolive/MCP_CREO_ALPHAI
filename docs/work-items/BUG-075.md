# BUG-075：Toolkit 状态探针偶发无效结果（invalid_probe_result）

日期：2026-10-20 登记。类型：缺陷。优先级：P2。状态：待复现。目标版本：未排期。

来源：[WorkBuddy 0.3.7 剩余事项验收](../WORKBUDDY_037_REMAINING_RESULT.md)第 0.1 节（当日唯一一次，黑盒记录）。

## 现象（2026-10-20 10:42 UTC，服务 0.4.2 / Creo 12.4）

- `creo_startup_status.channel_health = {connected:false, connection_state:"invalid_probe_result", worker_exit_code:1, message:"Toolkit worker returned no valid status result"}`，`state=timeout`、`snapshot.stale=true`。
- 同刻 `creo_session_status` 返回 busy（owner 为另一 session_status 探针），首个建模提交被 ready 门槛拒绝（未产生作业）。
- 按工具指引执行一次显式 `creo_startup_status(retry=true)`：约 40 秒内 `state=ready`、通道验证恢复；此后全部提交正常。未重启 Creo、未结束进程、未清保护、未重放作业。

## 待复现与定位方向

- 探针 worker（status 探针）退出码 1 且无有效状态输出的触发条件不明：仅发生一次，无法与并发探针、会话忙碌或瞬时窗口状态（同报告记录 parametric.exe 存在 hidden_only 窗口）区分。
- 复现时先取 `build/` 下探针日志与 worker 退出路径，确认是探针自身异常还是连接层竞争；再评估是否需要在探针侧增加一次有界自恢复或更明确的指引文案。
- 既有恢复路径（显式 retry 不重放作业、不清保护）行为正确，本条不改任何保护语义。

## 验收方向

稳定复现或定位根因后，同场景不再出现 `invalid_probe_result`，或给出明确原因分类；显式 retry 恢复路径保持现有契约。在此之前保持待复现，不因单次自愈事件调整通道逻辑。
