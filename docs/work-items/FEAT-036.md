# FEAT-036：零件特征删除、抑制与恢复

日期：2026-10-17。类型：功能。优先级：P2。状态：待规划。目标版本：未排期。

来源：[0.3.3 反馈补录](../validation/FEEDBACK-0.3.3-2026-10-17.md)报告 B 第 11 节；关联 FEAT-018/027、BUG-029。

## 目标与范围

为试错建模补充零件级特征 delete / suppress / resume，分别确认可用 SDK 路径及依赖处理。装配组件或图纸元素删除不能代替零件特征操作；重排序与未知结果恢复仍由原条目负责。

先确定 label/id、expected_revision、原生特征支持范围和操作结果。操作前明确父子依赖、共享引用与受关系控制对象；默认拒绝还是显式允许级联须选型，不得静默删除下游。删除后的标签/历史引用按 FEAT-027 保持身份边界，抑制对象与删除对象须能区分，恢复只能用于可恢复对象。未知结果保护期间拒绝新写入。

## 验收标准

| 环境 / 用例 | 可判断的预期结果 |
| --- | --- |
| Windows / 输入与状态 | label/id、过期 revision、不存在/已删除/已抑制对象、重复操作的结果明确；补保护回归并运行统一开发检查 |
| 本机 Creo 12.4 / 匹配 SDK | 用基础拉伸、切除及有依赖链的零件验证删除/抑制/恢复；实际特征树、材料、引用状态与查询一致 |
| 持久化与失败恢复 | 成功只推进约定 revision，保存重载 true；依赖冲突/再生失败按契约回滚，检查点和后续编辑可用，旧别名不误指新特征 |
| WorkBuddy | 仅 MCP 黑盒核对操作前后特征/体积、revision、保存重载和错误；未开放或未测的特征类型明确列出 |

## 实现与证据

本次仅登记需求，尚未确定公开工具或计划 op，未对历史或当前模型执行删除/抑制。来源报告不含逐类型最小用例，后续先限定范围再开发。
