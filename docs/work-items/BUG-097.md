# BUG-097：斜面草图 UV 映射与特征完成失败（L1/L2）

日期：2026-11-01。类型：缺陷。优先级：P1。状态：待复现（外部直改环境）。目标版本：未排期。

来源：[0.10.0 晚间包 03_BUG094报告](../validation/feedback-0.10.0-2026-11-01/originals/03_BUG094报告.md) 与 [04_generic_cpp_patches](../validation/feedback-0.10.0-2026-11-01/originals/04_generic_cpp_patches.md) §补丁 2；[逐章映射](../validation/feedback-0.10.0-2026-11-01/MAPPING.md)。关联 [FEAT-010](FEAT-010.md)、[BUG-087](BUG-087.md)、[BUG-095](BUG-095.md)、[FEAT-053](FEAT-053.md)。

**报告所称"BUG-094"与仓库 [BUG-094](BUG-094.md) 不是同一范围。** 仓库条目是 angle/offset/引用契约，其指定部分已随 0.10.1 验收；本卡承载晚间包新发现的 L1/L2，不覆盖旧条目的结论。

## 现象与待验证根因

外部直改源码后在 Creo 10 复现，三点定面基准面**创建成功且几何精确**（`id=47, normal=(-0.678,-0.093,0.730), origin=(-95.191,40.000,-88.395)`，与解析逐位一致），但在其上创建草图（`sketch` op 的 `frame` 形式）失败于 `ProFeatureWithoptionsRedefine`（`CompleteFeature = -1`）。三层现象：

| 层 | 现象 | 外部状态 |
| --- | --- | --- |
| L1 | `sketch frame` 的 `project()` 用 `ProSectionLocationGet` 的矩阵把世界坐标映射为截面 UV；**斜面支撑上 incomplete 特征阶段该矩阵恒为单位阵**，世界 XY 被当作截面 UV 写入（`LINE_tri_0=-95.191114,40.000000 → 44.838428,45.875213`） | 外部已加单位阵回退（改用 frame.u/v 基点积），实测修正为 `(0,0) → (190.382228,22.394433)` |
| L2 | UV 正确后 `redefine → ProFeatureWithoptionsRedefine` 仍返回 −1（斜面草图特征再生失败） | 待上游修 |

外部已排除：截面质量（`solve_profile` 成功、`SectionRegenerate=0`、闭合无自交无近容差点）、坐标锚（`SKETCH_ANCHOR_PLANE=2`）、再生时机（datum_plane 后插入 `regenerate` 无效）。推测方向为 `PRO_E_STD_SEC_PLANE_ORIENT_REF` 投影参照与三点定面父依赖的参照序问题，或 `PRO_SEC_ORIENT_DIR_UP` 在非水平支撑上需要换锚——**均为推测，未经本仓库验证**。

外部建议的定位手段：在 `ProFeatureWithoptionsRedefine` 失败分支把 `ProErrorlist` 的 `es` 内容带回执。当前 `errors(es)` 只 check 了返回码。注意 `native/geometry.cpp` 已遍历 `ProErrorlist` 并有 `last_feature_errors`，须**先找 CompleteFeature 路径的实际丢失点**，再补透传，而不是重新声称"此前没有 ProErrorlist"。

L1 与 L2 **各须独立取证**：只有日志 UV 正确不算 L2 修复完成。

## 范围

- L1：在斜面支撑上核对 section 坐标系与 frame 基的实际一致性；恒等矩阵**可能是真实合法位置**，不能仅凭 identity 切换 UV 映射，须由支撑面、section 的实际坐标系与往返测量证明映射。
- L2：在 `ProFeatureWithoptionsRedefine` 失败分支补结构化错误透传（API、code、element/type/error、失败阶段），保留原始 section 错误；有界样本上限 20，缺失明确 unavailable。
- 验证覆盖：identity 合法 XY、平移 XY、主平面 YZ/XZ、±54°、三点斜面、反向 U、编辑/重载；用世界↔section 往返点、法向与实际曲线位置验证映射。
- 不含：外部补丁直接并入（外部直改结果不算主干修复）；不得粘贴外部 identity-only fallback；不改旋转符号猜根因；不改 [BUG-087](BUG-087.md) 已交付的非平行参照修复。
- 三点定面本身归 [FEAT-053](FEAT-053.md)，本卡消费其结果；坐标草图整体能力与偏差口径归 [FEAT-010](FEAT-010.md)。
