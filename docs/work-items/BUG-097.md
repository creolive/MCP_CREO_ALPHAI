# BUG-097：斜面草图 UV 映射与特征完成失败（L1/L2）

日期：2026-11-01。类型：缺陷。优先级：P1。状态：待复现（外部直改环境；离线实现已交付，见下）。目标版本：未排期。

来源：[0.10.0 晚间包 03_BUG094报告](../validation/feedback-0.10.0-2026-11-01/originals/03_BUG094报告.md) 与 [04_generic_cpp_patches](../validation/feedback-0.10.0-2026-11-01/originals/04_generic_cpp_patches.md) §补丁 2；[逐章映射](../validation/feedback-0.10.0-2026-11-01/MAPPING.md)。关联 [FEAT-010](FEAT-010.md)、[BUG-087](BUG-087.md)、[BUG-095](BUG-095.md)、[FEAT-053](FEAT-053.md)。

**报告所称"BUG-094"与仓库 [BUG-094](BUG-094.md) 不是同一范围。** 仓库条目是 angle/offset/引用契约，其指定部分已随 0.10.1 验收；本卡承载晚间包新发现的 L1/L2，不覆盖旧条目的结论。

## 现象与待验证根因

外部直改源码后在 Creo 10 复现，三点定面基准面**创建成功且几何精确**（`id=47, normal=(-0.678,-0.093,0.730), origin=(-95.191,40.000,-88.395)`，与解析逐位一致），但在其上创建草图（`sketch` op 的 `frame` 形式）失败于 `ProFeatureWithoptionsRedefine`（`CompleteFeature = -1`）。三层现象：

| 层 | 现象 | 外部状态 |
| --- | --- | --- |
| L1 | `sketch frame` 的 `project()` 用 `ProSectionLocationGet` 的矩阵把世界坐标映射为截面 UV；**斜面支撑上 incomplete 特征阶段该矩阵恒为单位阵**，世界 XY 被当作截面 UV 写入（`LINE_tri_0=-95.191114,40.000000 → 44.838428,45.875213`） | 外部已加单位阵回退（改用 frame.u/v 基点积），实测修正为 `(0,0) → (190.382228,22.394433)` |
| L2 | UV 正确后 `redefine → ProFeatureWithoptionsRedefine` 仍返回 −1（斜面草图特征再生失败） | 待上游修 |

外部已排除：截面质量（`solve_profile` 成功、`SectionRegenerate=0`、闭合无自交无近容差点）、坐标锚（`SKETCH_ANCHOR_PLANE=2`）、再生时机（datum_plane 后插入 `regenerate` 无效）。推测方向为 `PRO_E_STD_SEC_PLANE_ORIENT_REF` 投影参照与三点定面父依赖的参照序问题，或 `PRO_SEC_ORIENT_DIR_UP` 在非水平支撑上需要换锚——**均为推测，未经本仓库验证**。

外部建议的定位手段：在 `ProFeatureWithoptionsRedefine` 失败分支把 `ProErrorlist` 的 `es` 内容带回执。当前 `errors(es)` 只 check 了返回码。注意 `native/geometry.cpp` 已遍历 `ProErrorlist` 并有 `last_feature_errors`，须**先找 CompleteFeature 路径的实际丢失点**，再补透传，而不是重新声称"此前没有 ProErrorlist"。

L1 与 L2 **各须独立取证**：只有日志 UV 正确不算 L2 修复完成。

## 范围

- L1：在斜面支撑上核对 section 坐标系与 frame 基的实际一致性；恒等矩阵**可能是真实合法位置**，不能仅凭 identity 切换 UV 映射，须由支撑面、section 的实际坐标系与往返测量证明映射。
- L2：在 `ProFeatureWithoptionsRedefine` 失败分支补结构化错误透传（API、code、element/type/error、失败阶段），保留原始 section 错误；有界样本上限 20，缺失明确 unavailable。
- 验证覆盖：identity 合法 XY、平移 XY、主平面 YZ/XZ、±54°、三点斜面、反向 U、编辑/重载；用世界↔section 往返点、法向与实际曲线位置验证映射。
- 不含：外部补丁直接并入（外部直改结果不算主干修复）；不得粘贴外部 identity-only fallback；不改旋转符号猜根因；不改 [BUG-087](BUG-087.md) 已交付的非平行参照修复。
- 三点定面本身归 [FEAT-053](FEAT-053.md)，本卡消费其结果；坐标草图整体能力与偏差口径归 [FEAT-010](FEAT-010.md)。

## 实现与证据

### 2026-11-01 离线实现（工作树 MCP_CREO_MechDog_q06，分支 codex/q06-tilted-sketch，基于 50636bf）

**L1（identity 占位矩阵的 UV 映射回退）** —— `native/generic.cpp` `sketch()`：

- 完整 4×4 identity 检测（1e-12），但**回退有合法性门槛**：只有当放置帧不可能是"世界 XY 过原点"（`frame.n` 平行 +Z 且 `frame.origin` 为世界原点）时，identity 才判定为占位矩阵并回退到 `frame.u`/`frame.v` 点积投影。identity 合法的位置（如命名 XY 面）保持 location matrix 映射——两处投影在该情形下本就重合。外部补丁的"仅凭 identity 即切换"未采纳；语义按当前源码重新推导。
- 诊断日志 `SECTION_LOCATION_IDENTITY=%d using_%s identity_plausible=%d`（`using_frame_basis` / `using_location_matrix`）。
- 成功回执新增 `section_location` 结构块（`matrix_identity`/`identity_plausible`/`uv_mapping`），同时写入 alias 的 solver 记录——L1 坐标证据可由 MCP 回执判读，不只靠日志。
- 一致性收口：回退时 `mirrored=false`、`section_normal_sign=+1`，椭圆轴对齐与 `COORDINATE_AXES` 判定、arc/往返报告的逆变换统一改用 `effective_loc`（回退时为放置帧矩阵，否则原样复制 `loc`）。非回退路径（主平面既有工作流）逐字节保持原行为。

**L2 前置（CompleteFeature 失败透传）** —— 丢失点定位结论：`native/geometry.cpp::errors()` **一直**遍历 `ProErrorlist`（日志 `feature_error element=…` 与无界字符串 `last_feature_errors`），"此前没有 ProErrorlist"的说法不成立；实际丢失点在下游——sketch 的 CompleteFeature 失败只产出 `Toolkit call CompleteFeature failed with code -1`，element/type/error 三元组与原始 section 求解错误都只留在 native.log。补齐：

- `geometry.cpp`：`errors()` 同步填充有界结构条目（样本上限 20，`feature_error_total` 保留总数）；新增有界 section 错误捕获（样本上限 20，`capture_section_error`/`reset_section_error_capture`）。
- `sketch_solver.cpp`：`section_errors()` 把 solve/autodim/regenerate 三阶段的原始 section 消息写入捕获；`solve_profile()` 入口重置，防止上一操作的旧消息串扰。
- `generic.cpp`：`redefine()` 失败时构建 `feature_errors` 回执（`api`/`code`/`failed_stage`/`element_errors{total,truncated,sample}`/`section_errors{available,total,truncated,sample,unavailable_reason}`）；`execute_operation()` 按操作清理并附加到失败操作记录；`run_generic()` 顶层 `catch(ProError)` 附加到 report 并在消息文本中给出有界 element 错误摘要（截断明示）；每次作业入口重置。
- `src/creo_mechdog/operation_results.py`：新增 `normalize_feature_errors`/`annotate_feature_errors` 有界投影（样本上限 20、total/truncated 保留、非整数字段置 null、section 缺失显式 unavailable_reason、缺块保持缺块不伪造），接入 `annotate_native_result`（report 级与逐操作记录同一投影）。

**测试与夹具**（全部离线，隔离桩 + 源码标记锁定接线）：

- 新增 `tests/unit/test_feature_errors_projection.py`（24 例）：投影语义（上限 20、截断、unavailable、非整数置 null）+ 原生接线锁定（redefine 先捕获后 check、按操作清理、逐作业重置、geometry 20 上限、BUG-087 修复未被触碰、L1 门控与诊断标记）。
- 扩展 `tests/unit/test_dev048_plane_frame.py`（L1 语义类：identity 合法 XY、平移 XY、主平面 YZ/XZ、±54°、反向 U、非 identity 不回退、六类往返 ≤1e-9）；扩展 `tools/test_dev048_plane_frame.py` 共享 L1 oracle（`uv_mapping_choice`/双向投影/往返），`offline_checks` 8→10 项。
