- 偏置距离新增独立status，不以面积available替代距离available；不未经验证把总量公式换成差量公式后宣称适用于曲面。
- 板厚保留API专用旧字段null含义；新geometry来源有明确适用门槛，API存在但失败不降级走自证。验证字段为value_mm，不另造value键。
- miter当前用BLIND，不回退未跟踪旧调研文件的GAP草案；默认不传仍拒绝，放行证据是对象，不把回显当几何定标。
- 原反馈D为native_planar首壁，已通过四壁驱动为conversion首壁，两个路径不能替换。163234报告整体与组均true；161949顶层false/组true需分列。
- 居中拟origin局部mm、默认[0,0]兼容；优先使用已有frame能力，并保持u/v/n与生长方向。若探针失败再选择有符号尺寸方案，不能先安排全局重构。
- 0.16.0已合入FEAT-004尺寸守卫，不重复A02集成；其他工作树只算分支事实。
- 真实原生回归成功需独立几何、保存重载true；失败需恢复/基线/revision保护。离线门控、历史正例、发布版与本轮结果分层。

## 0.14.0两件反馈增量设计

本次新增Downloads/0.14.0两件，与原0.13.0四件共6件分别归档；[新增映射](../../validation/feedback-0.14.0-2026-11-06/MAPPING.md)区分A的Creo10运行时与B的离线验证。C4552/闸门/LF/schema说明在0.16.0已修，重复项只补历史证据。

- **矩阵R05升P1：** I032残差/det误差约2.24085e-7，当前Python/native 1e-6均接受；外部0.14.0内核-2与高精度30°成功是精确A/B关联，不能当成已证内核阈值。冻结两入口与native的兼容准入设计后再修，不静默正交化、不直接称1e-9就是Creo要求，不增加部分提交。
- **BUG-114/R13：** 当前finalize和component_changes不消费cleanup证据。可信failed终态、同job创建/未保存/所有权/双查询一致且无其他副作用时，有限受管模型scope可判no_effect；保留原execution_status和旧failed登记。unknown_outcome不能凭absence单键解保护，同名会话障碍消失不保证可自动重试。
- **回滚与清理分域：** rollback_status=not_attempted和rollback_succeeded=false可与新件cleanup erased同时成立，本身并不矛盾。保留兼容字段，不把清理伪造成rolled_back，不全局去掉unknown；修正的是效果归因与过宽note。
- **请求来源R04：** manifest.operations是归一化执行视图，保留worker输入/旧full页兼容；提交增加operations_view=normalized及defaulted_fields/必要的有界请求来源，不把depth=1默认值说成用户传入，也不把归一化页改标签冒充原始请求。
- **正证据：** 0.14.0外部through_all命中/null/去料100、只读jpeg与人工目视通过仅关闭对应外部样例，不覆盖当前源码完整矩阵或作者所有图片，不改历史Release的原始未测段落。
- 原0.12.0/0.13.0归档已存在，0.14.0本次2件归档；0.12.1原件未提供仍列缺件。API列表版本延迟仍属观察，不未经取证改更新算法；发布措辞按实际兼容变化核定。
