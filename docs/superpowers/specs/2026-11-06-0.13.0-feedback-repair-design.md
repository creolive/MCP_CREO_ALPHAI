## 关键判断

1. **确定的代码缺陷**：`native/surfaces.cpp:168` 仍有 `if (!ProQuiltInit(...); quilt)`，返回码确实被丢弃。另有 `volume_after/source_area` 在已有实体和曲面上的计量适用性风险，沿用既有 Q03 调查，不能只修语法就称偏置计量全部可靠。
2. **高影响、未定因**：外部 Creo 10 出现普通追加 trim/thicken 时 Backup=-1 且回滚比较失败。与历史会话损坏或“投影曲线消费自身目标”案例不能仅凭同一错误码合并定因；新建 BUG-113 分别调查保存失败和恢复失败。
3. **已知跨 SDK 缺口**：板厚 body API 缺失路径显式产生 -1/null，已有 FEAT-058/Q01 几何兜底计划，接续实现，不新建同义缺陷。API 缺失、API 调用返回 -1、未找到材料 body 必须分别标识。
4. **默认回执缺口**：compact 有 32 KiB 预算但不等于轮询内容恰当；新曲面判据未在白名单中，列表复用完整 job 摘要，日志和非必要详细块仍占空间。不能以进一步删掉测量值解决体量问题。
5. **契约遗漏**：主力 execute_plan 的旋转字段无 description；surface family/reference、工作卡首页与实际交付不一致。矩阵底座和组件来源映射已有，不重做。
6. **能力扩展**：四壁、真正 quilt merge、多截面曲面放样、居中首壁和计划内几何选边需要新增能力或原生路线验证，不能混入小补丁并承诺一次完成。

## 明确不采纳的推断和捷径

- 不能因重启后恢复就宣布“重编译必然破坏旧会话”或要求所有升级强制重启 Creo；不能由 hung 窗口直接判定模态框。先给可核查事实、suspected/unknown 原因与人工处理建议。
- 不增加自动结束 Creo、重连、重建 IPC、清 unknown 或解除模型保护的入口；这些超出当前恢复纪律和本次规划范围。
- 不取消回滚特征/body 比较。失败差异先结构化，与保存基线、活动/空 body、特征身份、体积/几何核对后再决定是否有可证明的等价规则。
- 不默认重试 Backup、改用 Save 或补交作业；若未来要重试，需独立证明无副作用和幂等性，并登记新设计。
- `tail_bytes=8192` 是读取预算，不能直接等同于实际回传了 8192 B 日志；体量用真实序列化响应核对。
- 未显式启用 weld 的作业 `applied=false` 是默认行为，不能据此推断焊接未实现。当前 W01 矛盾已消除，外部旧包原文保留。
- `relief` 是 bend-end relief，不能直接视为 corner relief/miter；资格 eligible 也不表示角部干涉已解决。保持 adjacent guard，直到安全路线实证。

## 冻结的设计约束

- 单位 mm / degree；Python 不模拟 Creo 几何；新业务进 `src/creo_mechdog/`，保持根兼容导出共用定义。
- 新增运行时模块须进入实际源码与部署身份清单（含 `server._SOURCE_NAMES`、恢复部署指纹涉及的清单），并验证源码包收录；不得只修改版本号代表已部署。
- Toolkit 通道唯一，忙立即拒绝，不排队、不自动重试；终态在锁内收尾、释放后发布。所有原生回归串行。
- BUG-001 约束继续：本次不新建 Toolkit 连接、不启动/结束 Creo、不做故障注入、不清 unknown。后续实机需当次核对会话可操作性并满足授权；其他离线任务可以先做。
- 本机 dev 入口只用 E 盘 `MCP_CREO_MechDog_dev`。本机原生验收按 Creo 12.4.0.0/匹配 SDK；Creo 10 专项证据只关闭对应反馈，不恢复全项目双版本门槛；Creo 9 无 SDK 的事实保留。
- WorkBuddy 仅使用公开 MCP 做黑盒；不能要求读源码、Git、本地配置或运行 Python 测试脚本。开发、外部历史、本机原生和本轮 WorkBuddy 四种证据分列。
- 不改历史原件、已发布标签或同名附件；后续合 main 必须新版本 Release、四附件、远端摘要核对同流程完成。
