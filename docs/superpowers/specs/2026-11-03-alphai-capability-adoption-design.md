## 全局约束

- Windows x64 / Python 3.12+ / C++17；长度使用毫米，角度使用度。
- 本地开发服务仅 `MCP_CREO_MechDog_dev`，仓库路径 `E:\Projects\MCP_CREO_MechDog`。
- `bridge.py` 是 Toolkit 锁的唯一持有者；忙即拒绝，不排队、不自动重试；已接受的任务只轮询 `creo_get_job`。
- 沿用现有 model_id、expected_revision、job_id、检查点、保存重载和 unknown_outcome 保护。任何新能力不得清 unknown、杀进程、绕过收养限制或隐式接管外部装配。
- 新 Python 业务进 `src/creo_mechdog/`；`server.py` 只做工具注册/映射；根兼容包装继续共享定义。
- 新原生模块按现有构建方式接入，维护实际依赖和源码指纹；不顺带实施 DEV-003/004 的全局重构。
- 不复制对方固定 PID 选择、公司模型名、特征 ID、尺寸 ID、配置、二进制、SDK 或 `native/constants.inc`；必要常量由本机匹配 SDK 生成。
- 每项数值输入拒绝 bool、NaN、Inf；引用必须唯一；不能确认时返回 null/unknown 和原因，不能猜改。
- 新查询及列表遵守现有完整响应 32 KiB 预算、分页/有界样本及原始错误码规范。
- 单个任务由用户指派；并行代码工作使用相互隔离的 checkout，公共文件由集成人按任务顺序整合。同一 checkout 不同时切换分支或写同一文件。

- 验收参考本机 Creo 12.4.0.0 / 匹配 SDK 和许可；Creo 9/10 无当前证据时标未测，不设置双版本发布门槛。

## 能力边界与设计提案

1. **质量**：首版只读受管 part/sheetmetal/assembly；输出 kg、mm、mm³、kg/mm³、kg·mm² 和原始单位。必须有材料/密度及查询来源证明；缺材料不能退成密度 1 的“真实质量”。按 occurrence 汇总并计重复实例，真实骨架身份由 API 确认；缺件、未知单位或失败组件影响完整性。
2. **尺寸**：保留既有 `id/value`；增加可选 `expected_value`、`expected_symbol`、`expected_owner`。一次操作先验证全部尺寸再写入。旧值比较容差 `max(1e-8, abs(expected_value)*1e-8)`，在该尺寸对外数值单位下比较。revision 守卫继续先行。
3. **螺纹孔**：在现有 hole 上增加 `standard={series,size,thread_depth}`；与自定义沉孔/沉头互斥。`diameter` 仅在 standard 分支可省略；标准底孔直径来自可信安装孔表。首版盲螺纹孔，`0 < thread_depth < depth`，深度仍遵守现有 tip 契约。螺纹元数据不表述为实体螺旋牙型。
4. **原生平面壁**：新增显式操作，不改变已有 `sheetmetal_wall` 路线；首版为无下游依赖的矩形首壁。就地编辑保留 feature 身份，校验有符号 XYZ 包络、厚度和体积。四壁、corner relief 不随本项承诺。
5. **骨架**：先做独立最小原生探针；再冻结受管骨架和父装配的身份、依赖、保存点及共同提交契约。创建不能留下已登记半成品；不通过独立零件伪装标准骨架。
6. **关联**：首版只关联本批原生矩形壁与受管标准骨架的长宽；显式尺寸映射，保留其他关系、冲突拒绝。源尺寸改变后目标必须随动；跨模型提交失败无法证实回滚时，保护所有受影响对象。
7. **组件状态**：首版单层受管装配，显式组件 label/feature_id；支持 suppress/resume 及一个原子成对切换。组件是 occurrence，不能按模型名猜唯一实例。不支持嵌套写入或把显示隐藏等同于抑制。
8. **约束克隆**：复用现有 FEAT-049 planner，先完成单层 ALIGN/INSERT 的显式映射子集；其他类型沿用既有边界，禁止无声降级 fixed。
9. **草图**：首版已保存且受管的矩形草图，显式对称轴或四条模型直边映射；不操纵用户正在编辑的草图会话。coordinates 与自定义约束的互斥保持；投影边失效必须诊断。
10. **名称/派生**：首版独立无外部依赖 part/sheetmetal。rename 保留 model_id 并推进 revision；derive 创建新 model_id、revision=1，源件字节不变。装配批量改名、气弹簧运动限位联合改型不在首版。
11. **会话**：保留现有状态字段，增加逐字段来源、检查时间、年龄和 known/unknown；显式 `live=false` 默认只聚合已有本地证据，`live=true` 经同一通道做只读核验。不能按最大 PID 自动切换目标。
12. **产品规则**：首版仓库自带脱敏模板到计划的纯转换，不连接 Toolkit、不提交作业。用受管箱体/机架尺寸模板验证；公司气弹簧表可作研究来源，不作为力学/运动仿真实现。
13. **版本清理**：inspect/apply、显式 keep 清单、600 秒证据、幂等键；仅项目自有受管目录、已核实同模型族、无依赖/占用歧义文件。保留当前、检查点、源件/组件快照、回退文件及全部无法证明安全的版本。移入回收站，不声称事务回滚。

这些是规划者提出的首版边界。各子计划的首个契约步骤由该任务执行者与集成人核对实际源码及 SDK；有改变时更新本设计和对应卡，不能由依赖方自行猜接口。
