# 0.11.0 第十一轮反馈（R11）后续开发 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: 使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实施。步骤用复选框跟踪；用户负责派工，未获指派者不擅自开始实机。

**Goal:** 把 v0.11.0 反馈中仍未闭环的三类摩擦（旧检查点无外观基线、零变更失败不可恢复、取色需手工拼 UUID）做成"可自证 + 可回归"的离线交付，其余已闭环项不重复做。

**Architecture:** 保持 `server.py` → `bridge.py`（锁/终态）→ `generic_bridge.py` → 原生执行器 → Creo 的单通道；新增诊断一律沿"原生块 → `bridge.compact_job` 白名单 → `operation_results.py` 投影 → 工具描述"全链落地。离线实现可并行，原生实验/构建/实机由同一负责人串行。

**Tech Stack:** Windows x64、PowerShell、Python 3.12+、pydantic、unittest、C++17 + Creo Toolkit（`native/*.cpp`）、MSVC、`tools/dev_check.py`、`bridge.py build`。

**Spec:** [R11 归档映射](../../validation/feedback-0.11.0-2026-11-01/MAPPING.md)（逐章归属、已闭环依据、缺件）与本计划同时阅读。

## Global Constraints

- 新业务进 `src/creo_mechdog/`；`server.py` 只放工具签名/描述，业务逻辑不进该文件。
- 长度 mm、角度度；标签小写字母开头、仅小写/数字/下划线、≤28 字符；服务 stdout 只承载 MCP 协议。
- 忙立即 `isError=true`/`status="busy"` + `blocking_*`，不排队、不自动重试；已受理作业只轮询。
- 新字段只增不改：`rollback_*`/`material_*`/`preview_status`/`draft_geometry.flip` 等既有语义不动；旧 job 缺字段保持缺省，不推导、不补造。
- 原生实验/构建/实机先核 BUG-001/BUG-091 会话准入；不擅自连接/重启/结束 Creo、不清 unknown、不重提已受理作业。
- 本机 Creo 12.4.0.0 按改动范围验收；Creo 9/10 实机与 WorkBuddy 黑盒单列未验证，不外推。
- `docs/validation/` 历史原件逐字节不变；新归档另开目录。
- 本批不合 main、不发布；后续合入必须按 RELEASING 使用未占用版本号（候选 0.11.3）同批发布，不得覆盖 v0.11.2。

## Review Focus

1. **准入放宽的边界**：`refresh_baseline` 只放宽"缺 `appearance`"一项；不得顺手放宽身份/绑定缺口。
2. **状态机不扩散**：零变更失败以"保持 ready"为主，`ack_no_mutation` 只处理证据不足的历史现场；不得变成任意失败强制复位。
3. **取色可重放**：`random` 在工具层解析并回显完整调色板；计划操作只接受显式调色板，避免重放不确定。
4. **只增不改**：新回执字段与 compact 白名单按需追加，不裁剪失败原因、回滚证据与既有字段。
5. **闸门真实性**：新增单测必须能在缺省实现时失败，不能靠夹具自证。
