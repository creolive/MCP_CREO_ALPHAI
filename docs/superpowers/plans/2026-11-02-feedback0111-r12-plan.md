# 0.11.1 第十二轮反馈（R12）后续开发 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: 使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实施。步骤用复选框跟踪；原生构建与实机由同一负责人串行。

**Goal:** 修掉 Creo 10 首次构建的硬崩溃（`HEADERS` 缺存在性过滤），把坐标标注求解的整截面平移做成顶层可观测并试点固定原点，补 save/erase 两处引导文案；归档 0.11.1 原件并发布 0.11.4。

**Architecture:** 保持 `server.py` → `bridge.py`（锁/终态）→ `generic_bridge.py` → 原生执行器 → Creo 的单通道；新诊断沿"原生块 → `bridge` compact 白名单 → `operation_results.py`/`geometry_deviation.py` 投影 → 工具描述 + README"全链落地。已闭环项（`depth_basis`、零变更失败 `ack_no_mutation`）只记依据。

**Tech Stack:** Windows x64、PowerShell、Python 3.12+、pydantic、unittest、C++17 + Creo Toolkit（`native/*.cpp`）、MSVC、`tools/dev_check.py`、`bridge.py build`。

**Spec:** [R12 归档映射](../../validation/feedback-0.11.1-2026-11-02/MAPPING.md)（逐章归属、已闭环依据、缺件）与本计划同时阅读。

## Global Constraints

- 新业务进 `src/creo_mechdog/`；`server.py` 只放工具签名/描述。
- 长度 mm、角度度；标签小写字母开头、仅小写/数字/下划线、≤28 字符；服务 stdout 只承载 MCP 协议。
- 忙立即 `isError=true`/`status="busy"` + `blocking_*`，不排队、不自动重试；已受理作业只轮询。
- 新字段只增不改：`geometry_deviation` 既有字段与 `exceeds_warning` 语义不动；旧 job 缺字段保持缺省，不推导、不补造。
- 原生实验/构建/实机先只读确认会话可操作；不擅自连接/重启/结束 Creo、不清 unknown、不重提已受理作业。
- 本机 Creo 12.4.0.0 按改动范围验收；Creo 9/10、报告方 24 条带原件、WorkBuddy 黑盒单列未验证。
- `docs/validation/` 历史原件逐字节不变；新归档目录配套 `.gitattributes -text`。
- 不合 main、不发布直到 R12-06；0.11.4 不得复用 v0.11.3。

## Review Focus

1. **缺头门控不能变成静默降级**：缺失头必须出现在生成日志；存在头一个都不能少，枚举集合与 include 集合必须同源。
2. **位移必须可区分**：刚体平移与变形不得混为一谈；`translation_mm` 只能来自实测点，不得由 `max_point_mm` 推算。
3. **放行不等于精确**：`tolerance_source="request"` 且存在位移时，`accepted_by_request=true`；不得让调用方读成"完全精确"。
4. **原点固定只能试点**：参考不足或尺寸创建失败必须降级并留日志，不得让原本可建的草图因试点而失败。
5. **文案不含自动动作**：只给调用形态与链路，不新增自动擦除/自动接管；`managed`/`modified` 拒绝条件不变。
