### Q01：平面壁板厚兼容保护——FEAT-058

**读取策略：直接 body API 优先；API 缺失时采用受限的几何校验。**

- [ ] 几何兜底只适用于本算子创建的纯矩形壁：一个承载材料的 body、无孔及附加特征、无下游依赖、frame 与模型轴对齐。
- [ ] C++ 从实际几何读取法向厚度，与真实驱动尺寸、有符号包络、体积及记录交叉核对。`SMT_THICKNESS` 和记录仅作一致性检查。
- [ ] 不采用单独的 `volume/(length×width)` 作为板厚验证。API 存在却读取失败，或证据冲突、非有限、单位未知时，拒绝修改。
- [ ] 已有壁在首次写入前验证加载状态；同计划“创建→改型”标明证据来自当前计划，不能称为存档回读。
- [ ] 新增 `thickness_validation`、`thickness_loaded_validation`，包含状态、来源、数值、原因及证据上下文。保留旧直接 API 字段的含义和不可用时的 `null`。
- [ ] 每个操作分别发布裁决；顶层兼容摘要明确对应操作，避免创建结果遮蔽后续改型结果。
- [ ] 拒绝信息补全下一步：使用 `creo_new_sheetmetal(template="native_planar")`，等待成功终态后创建首壁。

### Q02：装配与拉伸失败可定位——FEAT-012、FEAT-008

- [ ] 在 schema、创建/更新工具和示例中统一说明：矩阵三行分别表示局部轴在父装配中的方向，`p_parent=p_local×R+t`。

- [ ] 补齐 `result.failed_operation` 和对应操作的错误信息：index、op、label、sketch、阶段、实际 Toolkit 调用及原始码。装配失败另带输入矩阵、行列式和正交残差。
- [ ] 诊断必须有界；无法取得的信息返回 `null` 及原因。再生失败的可能原因与已证实根因分开。
- [ ] 成功姿态复用保存重载后的实际 transform，标明来源和单位。
